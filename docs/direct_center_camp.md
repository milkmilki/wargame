# 无入口府直攻州治：大营与攻守接续

## 范围与规则

仅当目标州没有合法入口府、也没有可用前进营地时，合法战前集结点兼作大营。
普通先攻府战线不提前建后方大营。沿用 `staging_city_id` 与 `camp_city_id`，
没有新增持久字段、阶段、锁或冷却，地图及原生快照格式不变。

大营表示基地，不代表占府进度。`campaign_has_forward_camp()` 判断基地是否位于
目标州内并仍可合法驻留，执行阶段和战场合并保留优先级据此区分前进营地；
`campaign_has_rear_camp()` 识别仍在集结点的有效后方基地。

宣战移交、战时新建和后续执行共同协调基地。保留有效基地，取得可从后方基地
抵达的属府后才前移；州治占领后沿用原肃清流程。旧大营失守必须先判定，
不能通过改选基地覆盖失败。第三方易主、和平和通行权变化不算拔营战败。
后方基地仍存在不意味着目标可达，失去通往州治的路线沿用原失效／退出流程。

首轮备战目标为 `max(45000, 君主修正后的R, 2V)`；360天半额兜底仍需满足当前野战门槛及资源、路线、外交资格。真实野战失败进入 `HOLD_CAMP`，败军实际回营、
恢复，再以营内空闲、有效、可达的绑定军队超过当前 `0.9V`（征服者 `0.45V`）后发动下一波。赴州治不要求同时满足围城R，到达后不足R则封锁。
残留围城不能覆盖重整状态，并行交战不被行政结束，在途军不瞬移。

## 防守接续

现有防守活动索引新增派生的后方大营投影；每批次一次建立后方战线索引，在原
军队遍历中收集驻营或沿有效真实路线返回该营的存活绑定部队。
没有新增每日扫描或寻路；军队是否真实返回复用来袭命令的路线校验。

`campaign_defense_context()` 新增 `enemy_camp_ids`。对应战争和州战场的有效后方
大营保持原防守任务，不另占基地所在州的战场名额。恢复军、撤退军能维持任务，
但不计入有效敌军；有效兵力与入侵／来袭按军队ID去重，防守使用野战最低人数，零有效威胁保留最低一军。
空基地、退出战线、其他战争及失效路线不维持该任务。

出击先考虑威胁州治的敌军，再考虑基地；逐个尝试真实可执行目标，不能让不可达
目标挡住其他合法行动。敌占属府仍按原收复流程处理，不允许穿过敌府去打后方目标。

实际占领后方基地才触发拔营，击退军队本身不算。沿用集合对60天冷却、最后一场
真实野战结束后释放绑定、保留战争池以及次日规划接续；共用基地的多战线不叠加冷却。
首都失陷、占领归属和议和仍按原规则处理，不保证拔营后必然存在合法反攻目标。

## 回归与观测

`direct_center_camp.gd` 的181项检查已纳入 `run_tests.sh`，覆盖初建基地、普通入口府不回退、
残留围城、恢复与在途兵力、道路中断、第三方易主、可达前移、共享基地、战争隔离、
显示合并与现有快照字段。并行野战测试验证最后一场结束才释放失败战线。

真实夹具从第100天开始：

| 场景 | 实际结果 |
| --- | --- |
| 州治野战失败 | 第100天败退，169天完成营内恢复；残军2893不足以出击 |
| 补足第二波 | 第169天加入营内预备军后实际开拔，需求18000 |
| 陆路拔营 | 118天占领，119天释放旧线并反攻下令，120天建立原攻方防守 |
| 渡口拔营 | 127天占领，128天释放旧线并反攻下令，129天建立原攻方防守 |

上述是固定夹具观测，不是时间承诺。35天同步／分帧推进逐日比较完整原生快照；
镜像与军队存储顺序交换比较战线字段、配对和实际绑定部队状态，允许完全可互换
军队的ID交换，不放宽兵力、位置、行军、阶段、冷却或战果断言。
