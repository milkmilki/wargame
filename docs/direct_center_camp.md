# 无入口府直攻州治：大营与攻守接续

## 范围与规则

仅当目标州没有合法入口府、也没有可用前进营地时，合法战前集结点兼作大营。
普通先攻府战线不提前建后方大营。沿用 `staging_city_id` 与 `camp_city_id`，
没有新增持久字段、阶段、锁或冷却，地图及原生快照格式不变。

大营表示基地，不代表占府进度。`campaign_has_forward_camp()` 判断基地是否位于
目标州内并仍可合法驻留，执行阶段和战场合并保留优先级据此区分前进营地；
`campaign_has_rear_camp()` 识别仍在集结点的有效后方基地。

宣战移交、战时新建和后续执行共同协调基地。保留有效基地，取得可从后方基地
抵达的属府后才前移；州治占领后沿用原肃清流程。旧大营失守必须先判定，
不能通过改选基地覆盖失败。第三方易主、和平和通行权变化不算拔营战败。
后方基地仍存在不意味着目标可达，失去通往州治的路线沿用原失效／退出流程。

首轮备战目标为 `max(45000, 君主修正后的R, 2V)`；360天半额兜底仍需满足当前野战门槛及资源、路线、外交资格。真实野战失败进入 `HOLD_CAMP`，败军实际回营、
恢复，再以营内空闲、有效、可达的绑定军队超过当前 `0.9V`（征服者 `0.45V`）后发动下一波。赴州治不要求同时满足围城R，到达后不足R则封锁。
残留围城不能覆盖重整状态，并行交战不被行政结束，在途军不瞬移。

前进营地位于目标州内，也可能与州治之间隔着敌方属府。直攻州治的合法路由
不存在时，不能把“可达出击人数为零”当成缺少援军。实际回营、空闲且有效的
兵力达到原野战门槛后，复用既有攻府调度打通可达敌府，按原规则留守大营，
再沿真实道路进攻州治。兵力不足或仍在恢复时继续集结，出击比例与围城需求不变。

原入口府不再敌对、脱离目标州或失去合法集结路线时，重新从同一目标州选择
可达入口；已沿旧入口行军或交战的部队保留原任务。新入口使用正常集结门禁，
没有合法入口时退出过时的 `BREAK_IN`，重新建立直攻集结点，不能反复尝试
不可达的州治。入口失效可以触发重整，单纯的敌方兵力增加仍不撤销已发动攻势。

## 防守接续

现有防守活动索引新增派生的后方大营投影；每批次一次建立后方战线索引，在原
军队遍历中收集驻营或沿有效真实路线返回该营的存活绑定部队。
没有新增每日扫描或寻路；军队是否真实返回复用来袭命令的路线校验。

`campaign_defense_context()` 新增 `enemy_camp_ids`。对应战争和州战场的有效后方
大营保持原防守任务，不另占基地所在州的战场名额。恢复军、撤退军能维持任务，
但不计入有效敌军；有效兵力与入侵／来袭按军队ID去重，防守使用野战最低人数，零有效威胁保留最低一军。
空基地、退出战线、其他战争及失效路线不维持该任务。

出击先考虑威胁州治的敌军，再考虑基地；逐个尝试真实可执行目标，不能让不可达
目标挡住其他合法行动。敌占属府仍按原收复流程处理，不允许穿过敌府去打后方目标。

实际占领后方基地才触发拔营，击退军队本身不算。沿用集合对60天冷却、最后一场
真实野战结束后释放绑定、保留战争池以及次日规划接续；共用基地的多战线不叠加冷却。
首都失陷、占领归属和议和仍按原规则处理，不保证拔营后必然存在合法反攻目标。

## 回归与观测

`direct_center_camp.gd` 的181项检查已纳入 `run_tests.sh`，覆盖初建基地、普通入口府不回退、
残留围城、恢复与在途兵力、道路中断、第三方易主、可达前移、共享基地、战争隔离、
显示合并与现有快照字段。并行野战测试验证最后一场结束才释放失败战线。

真实夹具从第100天开始：

| 场景 | 实际结果 |
| --- | --- |
| 州治野战失败 | 第100天败退，169天完成营内恢复；残军2893不足以出击 |
| 补足第二波 | 第169天加入营内预备军后实际开拔，需求18000 |
| 陆路拔营 | 118天占领，119天释放旧线并反攻下令，120天建立原攻方防守 |
| 渡口拔营 | 127天占领，128天释放旧线并反攻下令，129天建立原攻方防守 |

上述是固定夹具观测，不是时间承诺。35天同步／分帧推进逐日比较完整原生快照；
镜像与军队存储顺序交换比较战线字段、配对和实际绑定部队状态，允许完全可互换
军队的ID交换，不放宽兵力、位置、行军、阶段、冷却或战果断言。

`campaign_forward_camp_access.gd` 覆盖被敌府阻断的前营、攻府命令保持、打通后
真实行军与攻城、连续两座敌府挡路、入口失效和恢复、命令缓冲提交、兵力不足
和恢复门禁，以及被宣战方反攻灭掉宣战方的真实事务，
检查战争、军队绑定、资源和最终事件只结算一次。

`campaign_neutral_route.gd` 补充中立道路管辖与混合控制州的检查。战争目标评分、
入口府候选与实际集结点共用真实军事路径校验；领土接壤不代表道路可通行。
州内有我方属府大营、部队驻营，或者部队正在回营，都不能单独证明进攻路线存在。
前营必须还能攻击州治或至少一个敌属府；真实已发出的进攻与正在交战的部队仍保留。

失去全部进攻入口时，共同记录进入结束流程，释放进攻执行任务与原战场名额，
随后从合法目标重新分配兵力。旧州仍有独立防守需求时保留真实防守，但不继续占用
已取消的进攻名额。旧宣战目标也必须重新校验道路，不能在释放后立即重建同一条
不可达战役。沿用现有撤离与行军机制，不赋予中立通行权，不触发拔营冷却或反攻资格。

行政州可能包含不同主权国的属府。州治仍由其合法中立主权国持有，而本战役守方
仍控制该州内的敌对属府时，合法目标是这些属府，共同记录继续存在；不能仅凭
州治不属于攻守双方就判为“目标被第三方取得”并撤军。被第三方临占的原交战州治、
敌对属府目标消失和战争退出继续走原结束流程。

独立国家的首都位于府时，投降事务必须包含真实攻下的合法都城府，以及该州内
胜者已经实控的败方法理属府。中立州治与未被占领的其他城市不随府级首都易帜。
回归通过真实攻府、首都失守和灭国清理验证正向胜利与被宣战方反攻，检查资源、
军队绑定与一次性最终事件。

朝鲜半岛卫州场景从原局第12600天的同一运行中状态对照继续至12720天：
旧版将昔里吉部攻兴国成都府的战役反复判为“目标被第三方取得”，召回部队后
重新创建；修复版保留合法敌府目标，于12611天攻下成都并完成兴国灭国清理。
卫成州治全程仍由中立卫国控制，两条独立进程的续跑均无脚本错误。
专项60项、主测试集502项、365天同步／分帧等价检查通过；日期是这次固定状态
对照的观测，不要求修改规则后的新开局沿用旧战况。

上游追踪进一步确认，成都首次被拆出卫州发生在原局第4980天：卫国4830天
全州起义后，母国4871天只收复成都；4980天与其他国家议和时，逐城飞地整理
以 `peace_enclave_transferred` 把成都赠予兴国。整州结算修复要求飞地包含完整、
同实控且同法理的州，叛乱与普通和平共享州治口径；详见 `state_rebellion.md`。

种子1、40国、欧亚遮罩的仁安复现场景中，筝从第3240天起有45000人空闲驻营，
补给100%，出击最低人数13501；前营到仁安的合法直攻路由不存在。第3900天
同输入状态应用修复后，第3901天下令攻府，第3920天检查已确认属府易主，第3921天下令
进攻仁安，第3931天追加后续部队；本次战况随后结束战争，仁安仍归仁。
该观测验证调度不再无限等兵，不构成攻城必胜或固定结束日期的承诺。

同局第3600天的运行中状态继续至4500天，共抽样43条进攻执行战线。除仁安外，
洺攻者勒蔑、托克托攻术赤、庆攻涡昌均有同类前营路由阻断；通用修复后均于
3601天攻府，分别于3641、3621、3641天向州治出兵。溱攻珑崖驻军供给为零、
粮仓不可达，属于真实补给限制；没有把其存活人数当作可出击兵力。

同一生成输入从开局至4500天的全程回放，另抽样334条进攻执行战线，发现旧入口
失效造成 `BREAK_IN` 无命令：洺攻淮阳反复重建战线，部分轮次持续约710天；
托克托攻弘吉剌也持续约710天。淮阳旧入口新川无合法集结点，龙原仍可经本国
集结点到达。第1050天同状态应用入口修复后，1051天重新集结，1071天攻龙原，
1091天向淮阳出兵。第3900天同状态复测，淮阳与弘吉剌分别于3941、3969天
发动州治攻势；继续至4500天的25条进攻执行战线抽样中，没有持续60天无行军、
无交战的候选。回放使用原局的种子、40国与欧亚遮罩，修复后的战况允许分叉；
这些观测不等同于原日志的完整运行状态一致性。

本轮 `run_tests.py` 选择的24个相关脚本全部通过；攻势专项最终104项、同步／分帧
规划专项106项、主测试集502项均零失败。专项同时检查入口重新可用后的缓存失效、
后方边界失去通行后在途军队路径保持，以及真实正向胜利和守方反攻的战争与资源清理。
