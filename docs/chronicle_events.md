# 战争与事件结束编年史

GameState.chronicle_events 是只追加的历史事实列表。战争、通牒成功、地方叛乱和继承权战争只在最终结算后写入一条记录；拒绝通牒不产生独立事件。

战争在建立 war_id 时保存参与国名和行政州治归属基线，合并战争时迁移账本。野战结算的真实军队人数损失按 campaign_war_id 累加，战争关系、州战线和领土事务全部释放后，在日边界生成主动方与被宣战方视角文本。双方分别使用自己的得失州、敌方伤亡和敌方实际灭国成员；因此被宣战方反攻并灭掉宣战方时，会记录“破之、取州、灭敌为郡”，不会把敌方的失州误写成自己的“州陷”。文本包含结算时快照的国名、州名和灭国后缀，不随之后改名重算。

政治事件直接在事务成功点记录。历史视图保存事件数组和未完成战争账本，快照版本为 21。家族树面板提供“家族树／历史记录”切换，历史记录按当前国家参与者筛选，不改变暂停状态。

历史正文使用黑色仿宋，复用地图文字的字体加载与跨平台回退。新战争文案直接使用保存的国家名，不额外添加“国”，也不删除名称自身的后缀；取州写作“取邯郸、晋阳”，不追加“州”。“州陷”“国除”“灭某为郡”保留为结果用语。已有事件文本不迁移或重算。
