# 野战出击与战线兵力需求

## 规则与口径

2026-10-05 的人数规则将行动资格、围城需求和备战冗余分别计算，避免双方沿普通增援的战力倍数反复追加兵力。

| 用途 | 人数目标 |
| --- | --- |
| 普通野战出击 | 严格 C > 0.9V，最低整数为 floor(18V/20)+1 |
| 征服者野战出击 | 严格 C > 0.45V，最低整数为 floor(9V/20)+1 |
| 正常备战 | max(45000, 君主修正后的R, 2V)；2V不打折 |
| 360天备战兜底 | 实际到场至少完整备战目标一半，且重新满足当前野战门槛、粮食、人力、路线与外交资格 |
| 战时进攻分兵与动员 | max(45000, 君主修正后的R, 野战最低人数) |
| 战时防守分兵 | 野战最低人数；有效威胁为零且任务存在时保留一军 |
| 到城后围城 | 按原有君主修正后的R；不足则封锁 |

C 是本次行动真实可投入正规军，排除恢复、其他战线绑定及其他任务。已经执行同一行动的军队只计一次。HOLD_CAMP 第二波要求实际回营、空闲、有效且可达。V 是目标州域和接触该州路段上的有效敌方正规军，防守保留同战争后方大营投影并按军队ID去重；虚拟守军、全国远方军队和隐藏骰值不计入。

V=0 的野战最低人数为1，空战线不能出击。45000用于进攻分兵，未成为野战出击硬门槛。90000第二战场资格、最多两个战场、分遣队、战报锁定和真实行军继续生效。需求下降不会结束交战、撤销已经出击的任务或释放锁定绑定。

## 入口与实现

- GameState 提供 campaign_field_minimum_manpower、campaign_offense_manpower 和 campaign_prewar_target_manpower；campaign_attack_requirement 取围城与野战的最大值，campaign_minimum_launch_requirement 仅代表行动资格。
- DiplomacyAI 的目标选择、备战、360天兜底与宣战提交共用人数规则；兜底和提交共用 war_preparation_launch_allowed，提交重新检查实际到场与当前条件。
- Simulation 的攻府、直攻州治、营地出击、第二波与守方拔营使用真实行动军团。分兵和动员使用统一分兵目标。普通战争关闭近邻主战与重点城市独立派兵入口，由战线分配联盟同侧兵力；有效在途承诺计入绑定量，不能充入实际到场量。
- 防守发现、接管与分配复用 campaign_defense_activity_index 的州域、后方大营、候选州、军队和交战索引；每批次复用，无逐候选寻路、每日持久预算或新增存档字段。完整职责与最新验收见[普通战争增援职责收口](campaign_reinforcement_ownership.md)。
- 近邻与重点城市旧入口仅通过 _succession_battle_context 服务皇子战争，保留其原战力规则；普通战争旧入口的人数公式与承诺辅助函数已删除。UtilityAI 的断粮突围／封锁救援价值评分仍有1.25估值；它不提交普通战线分兵或增援人数目标。全国1.10兵力预估仅用于战前粮食可持续性评估。

快照版本保持22；四骰、共享士气、军费战力和行军容量未修改。四骰基线提交为8556b9e；本人数规则与普通战争增援职责收口一并提交。

## 保留失败

- nation_detail_single_build：静态输出缺少动态面板的折叠Debug栏，section签名与行数两条断言失败；四骰基线复现相同两条，未放宽断言。
- ai_symmetric_duel：在对战前返回INVALID_ASYMMETRIC_FIXTURE（退出码2）；四骰基线同样失败。主逻辑套件中的城市镜像／军队ID置换等变回归通过，不能把这个夹具视为成功运行的长期镜像对战。
- diplomatic_battle_lifecycle：最终全套曾出现一次“repatriation starts real homeward movement without losses”失败；同版两次单独复跑及基线两次复跑均38项通过。记录为偶发失败，不声称已修复。
- 四种子长跑政治归属失败见上文。完整run_tests.sh因此不能报告全部通过；补跑继续覆盖后续门禁，常规脚本保留原失败停止规则。

本机普通Python缺少numpy时地图源工具测试无法运行；改用已有内置Python后LOW_POLY_SOURCE_TOOL通过，无依赖安装或断言变更。
