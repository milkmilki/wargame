# 正式欧亚陆路折线修复

2026-10-08：正式欧亚之前使用四邻接省份联合域寻路。在存在河流屏障且未启用严格候选交通时，`_coarse_province_pair_path` 直接返回格子中心折线。显示层准确读取 `Edge.map_path`，所以统一政治/贸易视图或修改降雨参数不会消除横平竖直的道路。

本次将道路简化单独接入正式清单的 `road_path_model: "visibility_v1"`，不切换 `full_network_v1` 候选交通。既有城市、省份、河网、码头和道路邻接关系保持原生成流程。在最终陆路上从已有折点中选取能直接连接的较远点；每条新增线段检查两端省份的联合域、原始4096高程像素、海陆、全段高差及主河交叉。无法合法简化的原绕行保留。没有加入装饰曲线。

新折线只保存到原 `Edge.map_path`，长度和游戏距离随实际路线更新；政治、贸易及移动继续读取它。移动城市后的道路重建走相同后处理，旧模板仍保留保存的路径。缺省道路模型为旧行为，其他地图源不变。布局缓存包含道路模型；新局日志记录模型及简化统计。

本次只处理 `LAND` 城际陆路；码头岸路、河运和海运路径保持原规则。
