# 区域整合停滞与目标选择修复

## 规则与边界

目标提案与实际行动分开。`select_war_objective()` 使用明确的
`ObjectiveContext.PREWAR` 或 `CAMPAIGN`，共享合法入口候选查询；提案优先入口府，
没有入口府时允许州治，不要求已经创建战线或绑定军队。
`administrative_tactical_target()` 保留战术兵力判断。备战到场、宣战和攻城门槛不变。

宗主主动扩张使用和平宗藩体系的真实领土边界，包括多层藩属；内战分支排除。
普通盟友边界不提供宣战资格，原国家级军事边界查询不改成宗藩查询。
备战集结点只允许本国与和平宗藩成员持有的节点，战前仍只抽调发起国自己的军队。

集结点须从发起国实控陆城或其存活军队的合法部署节点实际可达。
来源可达集合复用现有路径场，每个连通部署分区只构建一次；本国实控陆城作为
集结点可直接确认，不为普通本国边境新增寻路。索引仅在规划批次内使用，不增加每日任务。
不可达属国飞地不能产生备战目标；已有发起国军队实际驻在飞地则可作为来源。

本地渡口仍是两岸接壤，远程码头链仍不是陆地边界。无陆地候选时的既有码头远征
允许从实际可达的和平藩属码头出发。普通盟友可提供合法中转通行，但不能提供源领土。

候选、启动、重选、到场、通牒和宣战共用战前集结点查询。提交重新检查现实领土、
道路、外交和君主资格；法理收复例外保留。原有道路失效重选与取消流程继续使用。

普通退盟评分只加一次原有整合奖励，不再乘征服者倍率；盟龄、信任、共同敌人和
门槛不变，内部宗藩纽带不通过普通退盟解除。退盟不在同轮强制宣战。

没有新增持久化字段、状态机、锁或冷却；地图和快照版本不变。军队归属、费用、
占领归属、战争池、双州战场、战报和战斗公式均沿用现有规则。

## 自动回归

`run_tests.sh` 新增三项门禁：

- `regional_expansion_gates.gd`：47项检查，覆盖零绑定州治提案、行动门槛、宗藩与普通联盟
  区别、多层宗藩、飞地、死亡来源、内战、陆路／水路中断、上下文与版本缓存。
- `regional_expansion_e2e.gd`：真实行军后纳土，以及拒绝通牒后宣战、入境和占领；覆盖
  宗主经藩国边界及敌方码头渡河，陈旧宗属和禁攻君主动作提交均拒绝。
- `regional_expansion_determinism.gd`：镜像与可互换军队顺序下的提案、兵力池组成等价；
  同步与分帧备战、通牒的完整原生快照一致。

端到端夹具种子固定，仓库与君主任期明确配置。拒绝目标已有独立第三方战争，
因此按现有通牒资格必定拒绝；不通过放宽威慑评分或集结门槛制造战争。
藩国参与后，占领归属仍可能为实际参战藩国，验收按和平宗藩实控判断。

### 无入口府时的战役执行

州内仍有敌府不意味着必须先攻府。例如本方边境直连州治，唯一属府位于敌州治
后方，地图虽然连通，军队却不能以属府为攻击目标穿过敌州治。
此前战略层能选州治并完成备战，执行层却因属府存在而反复回到集结，600天仍未入境。

执行层现在以是否存在合法入口府决定部署路径，没有入口府时统一复用直接攻州治流程，
而非检查行政州是否包含属府。不增加阶段或持久字段；正常新战线保留实际到场兵力与
路径门槛，已通过备战并移交的军队在宣战轮按原先手规则下令。
`regional_expansion_e2e.gd` 新增后方单府真实链条，验证宣战同轮获得实际攻击命令、
行军及占领，并验证常规部署兵力不足、道路断开时不得出击。固定夹具集结25天，
从备战开始54天取得州治；并非所有地图的时间承诺。

实测：州治残余纳土集结41天；州治残余拒绝分支61天完成占领；藩国边界集结25天，
陆路66天、跨河88天完成州治占领。时间包含实际行军、规划等待和战斗，不是承诺的固定时限。

热路径改用版本化查询键，冷查询再协调评估缓存，消除了重复命中时的整批版本维护。
缓存优化前后固定负载完整快照指纹一致。

原诊断夹具中，州治残余宣战意愿从`-INF`恢复为72.904，并真实产生备战动作。
宗主经藩国边界亦产生备战；普通盟友边界仍拒绝。各类资源、共同盟友和禁攻约束保留。
