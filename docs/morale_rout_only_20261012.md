# 士气仅用于溃败（战斗规则 v7）

根据用户要求，士气不再折算部队属性与火力。相同兵力、攻防、补给、军费、君主倍率、地形、驻防和开场骰下，未溃败部队的实际攻防与伤亡计算不因士气变化而改变。

## 实现

- `Combat` 删除士气效率函数及其火力倍率。投入前线的兵力按各军实际攻击属性求和，再应用现有地形、驻防、发挥及攻城方向修正；防御沿用实际防御属性。
- 双方同时崩溃时按剩余兵力裁决；虚拟城市守军保留固有攻防折算，不再按士气打折。
- `ArmyPower.effective` 按 `size * sqrt(combat_attack * combat_defense) / 10` 估算战力，移除士气系数。补给已包含在攻防属性中，不重复应用。
- 战斗详情移除“士气战斗效率”行，明确提示士气只决定溃败。供给行按指标名称配对，避免删除一行后把君主倍率误标为供给。

士气仍按原规则衰减和恢复。道路野战与城下野战仍使用侧级共享士气及 `0.15` 溃败阈值，虚拟守军攻城仍保留单军 `0.05` 退出阈值。君主士气倍率及士气上限影响溃败前的储备；溃败后的撤退、恢复和 AI 对作战准备程度的判断继续使用士气。

## 兼容

`COMBAT_RULES_VERSION` 从 6 升至 7。新战斗日志可按 v7 重放；v6 及更早版本明确返回 `incompatible_combat_rules`，避免把旧日志按新伤害规则重算。没有新增状态字段，快照结构版本仍为 28，原生图计算接口仍为 2，无需修改 C++ 算法或重新编译扩展。
