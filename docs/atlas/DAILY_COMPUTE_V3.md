## 修改

敌军在没有粮道通行权的道路上移动，也会使请求国的整个补给网络缓存失效。
这些道路本来就不能进入补给搜索，重新计算不会改变结果。现在仅用可通行、容量大于零的
敌军占用道路建立缓存依赖；实际寻路仍收到完整敌军阻挡集合，真实封锁不会被忽略。

领土、外交、仓库可用性和围城变化仍按原规则失效；新增道路版本，防止开通道路后保留旧不可达结果。
旧网格及正在进行的继位冲突保留保守的完整阻挡依赖；进入继位冲突时改变指纹模式。
普通相机和显示代码没有改动。

## 同状态实测

三对独立进程，从完整第240天 Simulation 对象图分别推进241～270天，交替运行顺序。
固定 CPU4、亲和性掩码16，测量期间没有并发30年长跑。每次包含一天补给缓存冷启动。
Godot 4.7.1；headless计算，不含生成、快照序列化、审计及GPU渲染。

| 指标 | 修改前 | 修改后 |
|---|---:|---:|
| 整日日均 | 1828.26 ms | 1712.87 ms |
| 整日中位 | 1555.27 ms | 1563.95 ms |
| 整日P95 | 3606.24 ms | 3552.59 ms |
| 补给日均 | 359.67 ms | 253.03 ms |
| 补给准备日均 | 11.62 ms | 16.41 ms |
| 补给计划日均 | 314.55 ms | 204.29 ms |

整日日均减少6.31%，补给日均减少29.65%；过滤依赖增加了约4.8毫秒准备成本。
整日中位没有改善，收益不能描述为每一天都更快。剩余主要成本是AI、行军接触及补给冷启动。
不能把本轮比例与此前不同样本、不同并发负载下的比例相加，也不能推断实机帧率。

领土、编制、宗藩及库存不变量。灭国清理修复不在这段日期内触发，因此这份对照不能代替其独立回归。
