2026-10-10，以 `7e20b65` 为工作基线；正式场景 `atlas_military.tscn`，真实地球、种子1、40国。
本轮保留地图精度、气候公式、州府、道路和模拟规则，没有提交或推送。

## 改动

- 四季大气环流分别计算，在原来的季度顺序合并，保留浮点累加顺序；天气状态的先后依赖没有改变。
- 2048×1024栅格分条带处理。每条带保留原来的三角形回退状态和经线、极点规则；浮冰处理在合并后执行。
- 政治与州府显示几何、罩染、宜居度、海冰和海岸规划使用纯数组后台任务。共用一次海冰场；节点、字体、网格和纹理上传仍在主线程。
- 国家城市排序一次计算公共质心、方向和锚点，避免无首都时为每座城市扫描全体城市；镜像排序、首都选择规则不变。
- 缓存原生生成的地图输入及初始绘制数据。每次启动仍创建新的GameState、外交、军队、库存和历史，缓存不能恢复运行中的战局。

正常缓存目录为 `user://atlas_startup_cache/`，本机默认地球缓存已生成并验证。
缓存键包含种子、城市阈值、有效模型配置、引擎版本及现有源码／资源指纹；代码、配置或种子变化会失效。
压缩缓存通过长度和SHA256校验，损坏、缺失或版本不符时走原生生成；先写临时文件，再发布完整文件。
最多保留3份；当前默认地球每份约60.7 MiB。开发大体积输入与缓存不入仓库。
本轮验证工作区运行，没有执行新的发行导出验证。

## 验证与范围

- 当前综合回归55个独立入口全部通过，包含505项共享模拟断言、战争正反路径、模板恢复及35天军事烟测。
- `atlas_startup_climate` 对照优化前冻结样本，串行／并行季度、风场、降雨与模型元数据逐字节一致。
- `atlas_startup_raster` 对照优化前完整世界，串行／并行的全部栅格、经线、极点及浮冰逐字节一致。
- `atlas_startup_equivalence` 比较完整原生世界的网格、环境、省份、城市、道路、归属、名称、州府、交通及战略邻接，全部一致。
- `atlas_startup_cache` 覆盖参数排序、缺失、损坏、截断、重建及同秒淘汰；`atlas_startup_order` 覆盖标量排序、无首都质心、锚点和镜像。
- 真实GPU进程32964通过实际易主、前线、历史及四模式切换；交通和行政数据不变。
- 实际查看全图；排除右侧UI矩形后，767400个地图像素与修改前完全一致。没有整体降分辨率或删除道路。

旧离线 `atlas_climate_v5_consistency` 依赖 `.dbg/` 归档，其记录的环流源码哈希
`a08cc533…` 与本轮开始的 `7e20b65` 源码哈希 `91475c89…` 已不一致。

军事AI运行长帧仍按 `CACHED_RENDERER.md` 记录，本轮没有调整日结算法。

## 复现

```powershell
python run_tests.py --godot D:/ProjectICreate/Godot_v4.7.1-stable_win64.exe --group all --timeout 240
```

实机入口：`--script res://tests/atlas_startup_visual.gd`。
使用 `-- --atlas-no-startup-cache` 强制无缓存生成；`--atlas-startup-dir=` 可隔离开发缓存。
`--startup-evidence=` 指定实机证据目录。Windows后台实机启动使用隐藏窗口。
完整栅格和世界对照需要本地 `.dbg/startup-baseline/payload.bin`；这些开发输入不随交付程序运行。

线程组织依据 [WorkerThreadPool](https://docs.godotengine.org/en/stable/classes/class_workerthreadpool.html)
与 [Godot线程安全约束](https://docs.godotengine.org/en/stable/tutorials/performance/thread_safe_apis.html)。
