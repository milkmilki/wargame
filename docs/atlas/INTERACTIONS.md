# Atlas 2D 常用交互

入口仍为 `atlas_military.tscn`，保留启动缓存。贸易与君主核心已启用，见 `POLITICS_TRADE_INTEGRATION.md`；本次交互修复不改变模拟算法。

## 时间与镜头

- 默认暂停、1×。顶部两行工具栏提供暂停／继续、推进一天、1×／2×／4×／8×及减速／加速；完整范围0.25×～32×，倍率表示请求的模拟速度，实际进度受日结算耗时限制。
- 空格始终控制暂停／继续，包括按钮、下拉框、输入框有焦点以及下拉菜单已展开时；按住不重复切换，释放不触发按钮。生成或历史回看期间消费空格但不改变时间状态。`+`／`−`、`]`／`[`倍增调速，编辑输入框时不触发这些调速键。
- 推进一天仅在暂停且上一天结算完毕时可用，调用 `Simulation.advance_one_day()`，共享运行期异步结算、提交信号与在途保护。重复按钮、直接调用均不能重叠推进。
- 生成与历史回看期间禁用时间控制。返回当前后保持暂停和之前的倍率。
- 滚轮缩放、中键平移保持世界坐标相机变换；界面上的点击和滚轮不会穿透到地图。

## 查看和下令

- 政治、地形、宜居度、贸易区域模式空地单击打开实际控制国；府辖区模式打开对应州治直辖区／府辖区。可见政治填色的边缘即使没有对应府编号，仍能选国。
- 后台更新政治显示时保留最后一次地图选择，原子切换后打开信息；新世界、历史切换、模式变更或更晚的明确选择不会被旧点击覆盖。
- 可见治所标记或已排版的治所名称打开其信息；行军军队及交通点上的军队标记优先，治所驻军从辖区卡片进入。
- 州治使用带塔楼的大城图标，府使用房屋群；首都优先显示带旗城堡。复用已移植的civ-atlas矢量图形，按固定州府身份选图，不依赖干道主要城市标记。图标、文字避让和点击范围使用同一分类；无州府身份的独立预览保留原主要城市规则。
- 鼠标悬停可见城市图标时，图标在约120毫秒内放大15%，离开后缩回。放大范围同步用于点击命中；悬停与点击共用对象优先级，界面遮挡、拖动、生成及政治显示更新期间不提示底下的城市。离开窗口清除悬停。
- 悬停只更新城市实例的Shader参数，不更新实例缓冲、不重建文字布局、道路或地图几何；默认隐藏的城市名继续隐藏。疆域空地保持上面的国家／府辖区选取规则。
- 国家信息框的“概况”下方新增“州战役”：列出该国参与的进行中进攻／防守战役，显示战争编号、目标州、阶段、主导国家、本国投入、战线总兵力、集结地、驻营地、战术目标与重试等待。目标州、治所和主导国家可以点击查看。无战役时明确显示“暂无州战役”。
- 州战役兵力按当前军队的战线与战争绑定统计，包含共享战线中的盟军；本国投入单列。退出／退休战线、失效军队、错配战争绑定和战斗中冻结的认知兵力报告不计入。现有信息框每0.5秒更新，阶段、伤亡和目标变化复用控件；新增战役只重建这一栏目。
- 地图上的进行中战斗标记上方显示兵力比例条。围城从左到右为虚拟守军（深红）、守方野战军（红）、攻方（紫）；野战显示甲乙两方。野战军统计实际存活人数并包含盟军，不使用满编预算、战力或战争总人数。虚拟守军读取城市保存的守军人数；攻城结算期间若有临时守军对象则优先读它，不与城市存量叠加。纯封锁／攻城即使守方数组为空也显示“虚拟守军＋攻方”两段；城下野战时守军作为城内防御存量单列，不表示与野战军同轮参战。争夺围城权的两支外来军队不计入第三方城市守军。数字置于条上方，窄段不改变真实比例；条与字号保持固定屏幕尺寸，伤亡／增援时更新，结束后消失，静止时复用绘制命令。
  5项相关回归及RX7600实机1×／4×／8×和跨经线绘制检查通过；比例截图使用暂停地图中的1500／20000／20000展示数据，不作为真实战斗结果证据，见[兵力条验证](evidence/battle_strength/summary.json)。
  [纯围城修复](evidence/battle_strength/pure_siege/summary.json)另通过真实围城入口、封锁减员、临时守军挂载／移除等18项检查及5个相关回归；无野战守军的1500／20000比例条也完成相同缩放和跨经线实机验证。
- 历史政治快照没有保存州战役，历史国家信息明确标注“此政治快照未记录”，不展示当前世界的战役。此功能只呈现数据，不修改军事规划或战争事务。
- 信息框中的国家、首都、州治及军队链接继续使用现有信息模型。工具栏“国家”可搜索存续国家，按稳定编号显示首都、控制治所数与外交关系。
- 地图上的城市名称默认关闭，保留治所标记、国家名称与地理名称；可在“工具 → 城市名称”开启。关闭时不生成城市名称布局候选，治所仍可点击查看信息。
  自然符号、地理名称、城市标记均采用固定世界布局，缩放时等比例放大。国名只随政治数据更新，详见[静态图层](STATIC_RENDERER.md)。
  实机种子1／40国、1280×720、暂停下100个拖动及缩放输入验证通过；默认隐藏截图及记录见
  `runtime_performance_evidence/city-names-hidden-china4.png` 与 `city-names-hidden.json`。
- 查看对象、外交观察国、操控国、命令目标分别保存。查看敌国不会自动操控敌国；“操控此国”仍是显式操作。
- 右键从落点单独查询目标辖区并下令，不打开或替换信息框；“前往选区”使用最近一次地图点击的辖区。通过国家链接或列表导航后，不沿用旧的辖区目标。
- 海湖与地图外点击清除查看对象、外交观察国和目标。交通节点不作为治所；无人地块继续跟随托管治所。
- Esc优先关闭工具或国家列表，再关闭信息框。所有军事命令仍走原模拟器权限与事务入口。

## 外交、历史与缓存

国家或治所选择设置外交观察国。政治图自动着色：本国保留国色、敌国红、和平藩属灰、盟友绿、中立黑；其他模式保持原显示。藩属沿宗主链判断，内战打断和平归属，敌对优先。底部显示观察国、图例和“普通国色”；后者保留观察对象，关闭着色，下一次有效选择重新开启。关闭信息框退出观察。

`diplomacy_view.gd` 是卡片、国家列表和地图的共同分类入口。政治显示以RF国家编号纹理和小型颜色查表覆盖地图内部；高缩放曲线带使用同一查表。国家选择不重建逻辑编号、边界、道路、地形瓦片或文字。编号纹理在后台显示计划中准备，与政治几何和点击数据一起发布。现有红线／齿线前线独立保留。

历史信息统一取 `information_source()` 返回的政治快照。所选辖区的观察国随历史或实时控制权更新；页脚显示历史日期，不把当前军队、战斗和经济数当成历史数据。历史操作只读。领土更新发布期间延后处理地图选择，相机仍可操作。

## 贸易区域视图

顶部下拉框新增“贸易区域”，按实际 `TradeNetwork.trade_region_ids()` 填色，合并同区内部边界。金色圆环是每区按原经济规则选出的贸易中心，点击圆环可打开治所信息；空地仍查看实际控制国。托管无人地块跟随所属辖区分区，显示颜色不意味着当地新增人口或产出。没有新增贸易路线规则或海运。

贸易显示几何在数值工作线程中派生并缓存，主线程分批上传；同一世界模式切换、拖动与缩放复用。易主或君主变更可以改变贸易中心，区域几何不随国家归属重建。历史只显示冻结分区，不用当前经济数据计算历史贸易中心。

空格入口使用 [Godot 的输入分发顺序](https://docs.godotengine.org/en/stable/tutorials/inputs/inputevent.html)：主视口在GUI前消费；下拉弹窗独立视口也安装同样的暂停处理。

## 局部城市生成范围

主军事场景默认启用北纬20°～55°、西经15°～东经145°的城市生成遮罩。
进入“工具 → 限制城市生成范围”，可开关遮罩及调整四个边界；北纬／东经为正，南纬／西经为负。
点击“应用范围并重新开局”才生效，正在运行的世界不会按修改中的数值删除城市或军队。
存在行军、战斗、战线绑定时沿用禁止重建规则；生成、当天结算及历史回看期间不能应用。

遮罩在省份与州府选址之前将范围外适宜度、承载量置0。全球气候和地形保留；
范围外仍可有托管领土或交通节点，不新增治所、府或独立产出。旧模板未记录遮罩时保持全球模式，
加载后面板同步实际配置。详情与实机证据见 [SETTLEMENT_MASK.md](SETTLEMENT_MASK.md)。

## 战前驻守规则

驻城、驻边野战军不再仅因敌军人数优势主动退避。战败、士气崩溃及战役结束等必要撤离继续自动执行。规则与前后调兵／AI耗时对照见 [PRECONTACT_HOLD.md](PRECONTACT_HOLD.md)。

战斗图标及兵力对比条使用地图顶层标记，置于国界、前线、国名和贸易枢纽之上；界面信息框仍在其上方。实机已验证1×／4×／8×与跨经线视图的前线遮挡修复，见 [evidence/battle_strength/layer_order/summary.json](evidence/battle_strength/layer_order/summary.json)。
