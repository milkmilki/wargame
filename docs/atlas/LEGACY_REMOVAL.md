# 旧地图移除与正式2D入口

2026-10-09，按用户明确要求删除旧地图，正式入口改为 `atlas_military.tscn`，默认真实地球。新Atlas预览仍是同一2D模块的开发工具。

## 删除范围

- 旧 `main`、欧亚、中国统一、40国、500城压测与方格地图场景。
- 旧主控制器、整个 `scripts/view` 绘制/UI/3D管线及旧地形Shader。
- `assets/terrain` 下旧中国/欧亚高程图、蒙版、水文清单和数据处理缓存。
- 旧高度图城市、省份、道路与河流码头/渡口/河运生成模块、对应工具与专用测试。
- 旧地图模板3～8的导入/导出和DEM城市移动/路网重建代码；旧模板明确返回不支持，不能伪装成Atlas模板。
- 过期旧地图手册和测试命令；共享模拟测试中混杂的旧UI检查拆除。

保留军事、领土、经济、外交与统治者共享模型及其有效回归。合成网格移到 `tests/support/grid_world.gd`，包括可指定规模的无地理图夹具；这些测试验证共享模拟行为，不声称复现旧地形布局。Atlas专门测试验证真实地形、州府与物理路网。

## 两项旧失败的来源

1. “国家地图标签必须复用CJK Sans/黑体字体”：检查旧 `MapRenderer.create_map_label_font` 的代码文字。Atlas使用上游LXGW WenKai手写字体，这个风格契约不适用。
2. “2D贸易路线必须只在TRADE模式且存在路线时绘制”：检查旧 `MapRenderer._draw_trade_routes` 的代码文字。该绘制器已删除，当前Atlas军事贸易显示未启用。

随旧绘制器删除上述专用检查，未修改军事算法来绕过断言。另一个旧欧亚水文“6个河岸格未覆盖”检查也随水文交通管线删除。新Atlas仍保留环境水文，其用途和算法不同。
