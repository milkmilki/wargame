# 君主修正只读组合表 v19

## 卡点与实现

同一欧亚战争状态诊断PID23004：35天调用 `RulerProfile.modifiers()` 34067次，日均计时6.192ms；第210天调用4689次、30.084ms。计时有逐次包装开销，不是整个AI耗时。

既有接口每次复制原型基础值、规范化特质，再执行同样的特质乘法与储备修正。现在在脚本初始化时为10种合法原型、12种特质的单特质与双特质组合生成780条固定记录。构造继续使用原 `_apply_trait()` 运算和原字符串排序，内部记录及外层表均设为只读。

每次调用仍读取当前原型与特质，沿用原规范化、去重、截断及显式覆盖规则；没有特质时保留原基础值复制路径。有特质时查表并返回新的可修改Dictionary，避免调用者修改共享记录。不依赖国家编号、日期或版本号，没有跨世界的可变结果缓存，后台线程只读表。特质数量上限变更时需同时更新表构造。

未改省份、道路、行军、补给、外交、贸易、模板或启动入口。前两版守军依赖缓存未证实整日收益，已完整撤回，只在本地诊断目录保留原始实验；本次提交不含其实现。它们的统计汇总单独记录，不能混作最终收益。
