# Atlas 战争集团缓存优化 v10

2026-10-11。继续当前未提交工作区的日均性能优化；本轮不提交、不推送。

## 问题与实现

真实欧亚战争状态中，战役准备每次都重新调用 `GameState.coalition_campaign_components()`。十天诊断显示：单次分组平均27.6ms，而军事活动索引约3.1ms，战线整理不足1ms。分组根据战争、联盟与国家接壤计算，军队位置、规模、粮食、守军变化均不改变它。

Simulation 的 Atlas 分支现在只保留一份当前战争集团分组。输入包含世界身份、领土/道路/行政/外交版本，以及实际外交关系、战争编号、国家存亡/继承代理身份、继承战争双方和藩属内战阵营。使用完整序列化输入比较，不依靠短哈希；原地修改阵营、战争编号或存亡状态同样使缓存失效。新世界和 `setup()` 清理缓存。

规划器收到独立的深复制，添加 `defense_centers` 或修改成员数组不会污染长期分组。和平世界的空结果也可复用；只保存当前结果，不积累历史版本，不进入模板或编年史。缓存在军事规划主线程使用；后台补给不读写该字典。旧网格世界继续直接查询。`ai_coalition_component_cache_disabled` 仅用于对照验证。

军队位置、入侵、防御需求、战线绑定、战报、动员和最终命令仍实时计算；未改变决策周期、战争权限、目标选择或资源规则。新增 `ai_campaign_components` 分阶段计时，将分组耗时与其余战役准备分开。

## 同状态测量

使用真实地球种子1、40国，欧亚遮罩20°～55°N、−15°～145°，贸易与君主开启。输入是第180天完整运行中冻结状态，1192个节点、234支军队；对照双方从同一输入推进第181～215天。原版分组通过测试开关恢复，其余代码一致。加载源码哈希和生成冻结状态时的源码哈希分别保留，不能混为同一版本。

性能数据及所有完整每日快照摘要见 `evidence/coalition_cache_v10/summary.json` 和各个 `paired-*.json`。测量为 headless 模拟计算，不能当作 GUI 帧率；只覆盖一个当前战争状态，不构成30年审计。父子阶段不可重复相加。

五次独立进程均串行测量两个变体；前三次先关闭缓存，后两次交换顺序。下表为各进程35天均值的中位数：

| 项目 | 修改前 | 修改后 |
|---|---:|---:|
| 全日平均计算 | 318.07ms | 301.94ms |
| AI处理 | 188.21ms | 172.68ms |
| 其中战役规划 | 67.18ms | 50.87ms |
| 其中战役准备 | 32.70ms | 16.18ms |
| 其中战争集团分组 | 27.19ms | 10.45ms |

全日中位数减少约5.07%，逐进程配对改善比例的中位数为4.99%；单进程改善在2.05%～5.77%之间。战役规划减少约24.3%。易主或外交变化仍需要重算，所以战争分组耗时没有降到零。175组完整每日快照摘要相同，五次加载源码哈希均与当前实现相符。

实际PID为24208、25092、9364、13140、14456。相机、文字、纹理及渲染器本轮未改；不将这组结果说成拖动帧率改善。优化后行军交战仍约51ms/日，其他AI阶段仍占主要成本，整体性能目标尚未完成。

### 峰值核对

用户随后将目标扩大到日均和峰值耗时，追加核对全部日结算分布：每个进程35天P95的中位数约602.69→610.55ms；各进程最慢一天的中位数1197.07→1207.17ms。**本轮未证明峰值改善。** 不用平均值下降代替尖峰验收。

五次最慢日均为第210天（月度结算日）。例如PID14456的优化后总计算1180.58ms：月度结算645.86ms，其中外交411.44ms；随后AI414.70ms。外交选择140.04ms、动作提交142.91ms、关系整理70.28ms是其主要子阶段。同日外交变化使战争分组重新构建，暖缓存对这个尖峰帮助有限。

后续优先检查月初外交及其同日触发的AI集中刷新；日均优化和峰值优化分别记录。此处是同步模拟日结算计算时间，不是分帧运行中的单帧卡顿时间。

## 验证

`atlas_coalition_components` 先在旧版失败，再检查暖缓存、空世界、调用者修改隔离、宣战联盟/议和、真实控制权转移、道路与行政变化、直接存亡/外交变化、继承战争排除、内战阵营原地变更、战争编号迁移、关闭缓存及新世界隔离。

`atlas_coalition_runtime` 使用两份相同真实欧亚输入，自主推进60天，再将关闭缓存的同步结算与缓存开启的真实分帧日结算对照5天；比较完整 NativeSnapshot，并要求确实存在州战线。

同时回归核心模拟、AI错峰、双边战场/联盟调兵、战报锁定、藩属内战、州府事务、区域战略、贸易君主集成与补给后台路径，以及主动方胜利和被宣战方反攻灭国。
