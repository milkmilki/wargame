# 内陆水汽与全年湿热修正 v5

真实地球独立预览默认使用 `seasonal_circulation_v5` / `climate_capacity_v5`。相同种子1、球面网格、真实高程、海陆及显示温度；没有按里海、刚果、中国坐标设置降分或降雨值。本次只修改独立 atlas 子系统，不接入军事、贸易。

## 修复机制

- 将真实水体分类0陆地／1海洋／2内陆湖泊传入1°环流。里海为湖泊，黑海与地中海仍是海洋；不根据粗网格是否连通来推断，避免把直布罗陀窄海峡截断后的地中海误认为湖泊。
- 内陆湖泊保持同一温度饱和水汽计算，蒸发补湿速率取海洋的0.10，初始湿度不预填至饱和。湖泊季节热振幅系数24（海洋5），寒冷季节在−2至1℃间冻结减弱补湿。这是有限湖面输送的游戏代理，没有独立求解湖泊热量、盐度或蒸发水量。
- 低洼封闭湖泊盆地的温带干空气混合：从水体连通分量及邻岸原始高程识别低于海平面的内陆湖泊，排除直接连接海洋的水体；不使用湖名或坐标。混合项只在距这类湖泊600–1000公里内渐减、且离湖泊比海洋更近的区域启用。一般大陆平原不启用此项。距海洋200–1000公里渐增，每160公里输送步按 `exp(-混合强度 × 160 / 240)` 衰减；纬度30–40°渐增、50–55°渐减；迎风抬升200–1000米时渐弱。仍携带较多水汽的气团连续减弱此项，避免把海洋供水充分的平原仅因距海远就判为干旱。它是显式经验项，不是完整大气质量／能量守恒求解；热带对流、亚热带季风与高纬冷气候不套用深内陆最大混合。
- 在直接由湖泊水汽供给的山前平原，加入未来160公里内下游高程上升量75%的迎风抬升代理；只按上游湖泊份额启用，避免内陆丘陵把中原季风雨量翻倍。
- 保留短时天气状态；暖锋扇区向极输送，冷锋扇区增加向赤道的风分量，使海湖水汽能进入北向迎风山地。保留原有两种暖湿锋面，增加独立冷锋状态；三种短时状态各输送12步、采样后6步，冷锋权重为暖锋单扇区权重的0.8，局部总权重始终归一化（冬夏背景72%／暖锋各10%／冷锋8%，春秋背景55.2%／暖锋各16%／冷锋12.8%，寒冷大陆再降低各锋面份额）。
- 温度满分仍为10–20℃，20–28℃连续加速下降至0，取消旧版20–24℃仍保留85%以上得分的肩部。
- 四季各自计算温度×降水得分，取最好的两个季节均值的1.5次方，再乘全年负担：`exp(-1.5 × 四季平均湿热负担 - 四季平均过湿负担)`。湿热负担在20–26℃、季度300–800毫米之间连续增长；过湿负担在季度800–1400毫米间增长，寒冷季节减弱。冬季低温不降低两个良好生长季，但其他季节持续热湿不再被完全忽略。
- 淡水、湖岸和海岸加分同样受最终气候因子限制。没有导入观测土壤、疾病或现实人口；最终宜居度仍是游戏城市布点代理，不等同真实人口密度或农业产量。

## 复现与兼容

旧v4的环流与评分模块逐字冻结。明确指定旧模型时沿用旧默认评分；旧快照不升级。`atlas_climate_v4_compatibility.gd` 校验环境、风、四季降水、气候与最终评分逐数组一致，732个省份编号和治所一致，旧快照往返不变。

原始数据在 Godot 中计算，`atlas_export_rainfall_v5.gd` 保留v4对照并另存v5；Python仅投影和绘图。地图显示为4096×2048插值，输出图5120×2880，正式环流求解保持1°；0.5°实验因显著全图偏差未启用；高清不增加模型精度。

### 仍存在的实际偏差

- 里海南岸测试点年雨量约741毫米，但过度集中在夏季（约607毫米），秋冬仍偏干；南岸窄平原在33940个球面地块与1°求解中也无法完整表达，宽区域均值不代表该条沿岸平原。
- 里海北东测试点已从861／1129降至341／366毫米，仍只是宽界通过，不等同北岸160–230毫米的实测分布已精确还原。
- 雅库茨克冬季与夏季仍偏干，非洲东南仍偏湿。土壤、病害、农业技术与现代人口未纳入；不能由这张游戏宜居度图直接推导真实人口密度。
- 现有 Godot SubViewport/纹理退出时的资源泄漏警告仍存在，与此前基线相同；本轮没有修复渲染资源生命周期。
