# 两季封顶宜居度 v6

2026-10-09，真实地球预览默认评分更新为 `climate_capacity_v6`，降雨仍为 `seasonal_circulation_v5`。本次仅修改季节得分的汇总机制，保留现有温度、降雨、地形、群落、环境供水，以及每季的温度／降雨曲线。

## 规则

每季得分仍为 `温度得分 × 当季降水得分`，范围 0–1。选取四季最高的两个联合得分：

`气候支撑 = min(1, (最高季得分 + 次高季得分) / 1.6)`

累计 1.6 达到气候支撑上限；四季均满分不会再提高上限。单季满分、其余零分时为 0.625。移除 v5 的最佳两季平均值 1.5 次幂和全年普通湿热／过湿额外惩罚；过热、过湿仍会降低其所在季节的联合得分。阈值 1.6 是游戏参数，不是实测农业常数。未加入作物、连续生长季、土壤或灾害模型。

环境供水、海岸条件、海拔与坡度照常参与最终宜居度，因此气候支撑封顶不代表所有地区最终宜居度相同。适宜季节折算月份仍汇总四季，用于详情诊断；它不是封顶后的粮食得分。

## 运行与验证

- 评分测试先复现 4 项失败，修改后全部通过；覆盖两季饱和、单季部分支撑、其他季节不扣分、雨热错季、极端温度／降雨和有限范围。
- 新默认完整原生环境生成与冻结 v5 对照：网格、海陆、高程、温度、四季降雨、风场、群落、环境水文和海冰完全一致。
- v5 评分代码逐字节保留；无缓存重算 v5 宜居度与 v5 省份完全一致，旧快照不会自动升级。
- 同输入当前评分重复计算一致；新宜居度逐地块不低于 v5。
- Godot 4.7.1 / D3D12 Forward+ / AMD Radeon RX 7600 实机生成，PID 28184，757 省份、681 城市、766 路段，快照验证通过。
