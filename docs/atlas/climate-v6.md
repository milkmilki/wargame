## 当前第二轮结果：季风、地形阻挡与沿岸海温

模型标识仍为 `seasonal_circulation_v6`，实现修订为 `thermal_monsoon_terrain_v2`。第一轮场和源码保存在忽略目录；以下与同一输入、同一观测的第一轮比较，不把 v5 当本轮起点。当前运行时仍只使用海陆形状、DEM、纬度/季节规则和有限水循环。

改动机制：

1. 区域大陆热低压对附近海洋产生平滑的气压梯度响应，考虑旋转和大陆摩擦；高原加热影响夏季雨带推进。保留热带季风带，同时让副热带锋面随夏季加热向极地移动；海洋热惯性延续秋季沿岸锋面。
2. 风先响应地形，再输送水汽；阻挡部分越岭分量，并沿原有等高线方向偏转。每个1°气候格补采3×3 DEM点，采用中心高度加60%亚格峰值差作为输送屏障；不抬高用于气温的地面、不修改真实海陆分类。
3. 以源海岸法向与背景风推断有界的沿岸 Ekman 上升流/下沉流，南北半球方向相反；季风反转可以松弛静态寒流代理。短暂锋面不瞬时重设整季海温；原生地图显示的年海温异常取同一四季边界的平均。
4. 高原上方干空气、背风下沉、冷海温和低层辐散限制抬升。高原稳定层仅作用于面积至少500万平方公里的大陆，区域平均高度300–750m平滑启用，避免小岛与低丘陵被误判。稳定性系数不直接删除水汽；极端云水有界转为降雨，未转化部分继续输送。所有抬升解除系数限制在0–1，避免负下沉或水汽放大。
5. 森林/土壤仍走有限水桶和预测/校正；既有城市评分公式与用户的0.60间距下限保留。模型参数属于游戏尺度近似，并非实测风、压力或海温反演。

物理方向参考：[NOAA全球环流](https://www.noaa.gov/jetstream/global/global-atmospheric-circulations)、[NOAA/PMEL风驱动海洋响应](https://www.pmel.noaa.gov/news-and-media/highlights/steady-state-ocean-response-wind-forcing-extratropical-frontal-regions)、[东亚锋面降水研究](https://journals.ametsoc.org/view/journals/clim/23/1/2009jcli3128.1.xml)、[索马里上升流研究](https://agupubs.onlinelibrary.wiley.com/doi/abs/10.1029/2009JC005439)。这些来源支持机制方向，不为游戏经验系数提供精确数值依据。

## 实现

1. 保存 v5 降水源码作为显式历史模型；先写通用季节/水量守恒测试和独立观测区域诊断。只调整新的 v6，不改历史版本和城市密度修改。
2. 改季节副热带下沉带、海洋稳定层和地形降水分配；用同输入导出逐季/年度网格对照，修复主要空间/季节偏差。
3. 加有限森林根区/土壤水桶：记录降水、存量、蒸散、出流和年际循环；无水输入不产生蒸散，干季可使用此前存水，全年水量收支闭合。森林覆盖从模拟气候推断，标明这是潜在自然植被，非实测土地利用。
4. 接入默认地球、环境诊断/biome和缓存版本；回归真实地图、城市/道路和历史模型，实际渲染检查图层并记录生成耗时。

海温异常现在从完整的 1° 海陆网格求洋盆宽度、距东西两岸距离和既有纬度曲线。原来的不规则网格海岸顶点可能与陆地落在同一个粗格中，导致洋盆宽度归零；海岸加密顶点直接平均还会偏重小地块。新规则保留西岸寒流、东岸暖流的几何代理，但没有预先指定任何国家的气候。

环流修正赤道陆地加热的符号跳变；西岸夏季下沉、冬季锋面出现率由纬度、季节和陆海形状控制。寒流稳定层同时限制地形凝结和普通抬升，避免山地凝结项绕过逆温。年降水只有一个全球水柱换算系数，没有按区域调降水。

有限根区容量为 `75 + 225 × 潜在森林覆盖` 毫米，森林增加入渗、截留和蒸腾。每季细分三个均匀月通量步骤，防止整季雨量先一次性溢流、随后蒸散清空湿润森林的假象。根区从空桶重复气候年到周期平衡；每步满足 `前期存水 + 降雨 = 后期存水 + 蒸散 + 径流`，不凭空补满。前一轮气候产生的有限蒸散再作为大气水汽源，默认一次预测/校正，最终降雨重新结算地表水账。最终森林类型参考缺水季的 ET/PET，径流驱动原有环境汇流。

字段单位：`quarter_precipitation` 仍为年化速率（每季乘 0.25 才是季度毫米总量）；`surface_evaporation`、`surface_runoff` 和 `surface_potential_evaporation` 为季度总量，`soil_moisture` 为季末毫米存量，`annual_evaporation`、`annual_runoff` 为年总量。新字段通过模板验证/序列化，旧模板没有这些字段仍可读入。启动模型标识升为 v6，并沿用源码指纹失效机制。

## 验收与实现约定

- 定量：预先固定 20 个气候验证区域及共同陆地掩膜；争取全球年/季降水 MAE 同时改善至少20%，区域误差和退步项如实报告。观测不参与运行时输送或按区域纠偏。
- 地理：保留亚马逊、刚果湿润核心及南亚/东亚夏雨；副热带干旱核心不被森林反馈灌湿；西岸冬雨与内陆夏季水分梯度更合理。精细海岸/山脉误差受1°气候网格限制。
- 数值：有限非负，年值等于四季年化速率平均；同种子确定性、日期变更线连续；串行和并行一致；无海水/初始存水时零降水、零蒸散；局部地表水账闭合。
- 兼容：显式 v2–v5 使用历史函数；旧模板可以加载；新默认版本和生成源码指纹使启动缓存失效。原有两季城市评分和 0.60 间距下限保留。
- 性能：使用实际欧亚 seed1/40国/遮罩核对生成耗时，不用全球战争缓存代替；气候只在生成期计算，不增加逐帧气候模拟。
- 风格：沿用静态 GDScript、PackedFloat32Array 与可审计元数据。例：`evaporation = minf(demand, available_water)`；禁止只调整渲染色表冒充气候改进。
