# 当前项目交接

正式入口：`res://atlas_military.tscn`，Godot 4.7原生2D，默认真实地球、种子1、40国，欧亚遮罩北纬20～55°、西经15～东经145°；开发分支 `feature/civ-atlas-godot`。

旧欧亚/中国高度图入口、地图绘制器、3D资源及旧地形/水运生成管线已删除。`GameState` 只接受Atlas世界或Atlas版本9新局模板；共享军事、经济、外交和君主数据模型仍保留。合成网格生成位于 `tests/support/grid_world.gd`，不能作为游戏入口。

真实地球使用降雨v5、宜居度v6（两季封顶），原城市成为州治，州内最多三个府。行政划分固定，控制权和法理归属由现有领土事务维护。交通节点不计入城市/资源/占领目标；共享物理道路供行军、补给和野战共同使用。

新局启用贸易、君主特质、家族与继位；君主经营区域限制主动扩张。旧模板沿用其模拟开关，海运关闭。地图模板不是战役存档。运行日志写入 `user://debug_runs/`；改变入口或生成流程必须保留实际PID、种子、配置、来源与world_index，并保持模拟随机流不变。

验证：`python run_tests.py --godot <Godot路径>`，默认共享回归+Atlas军事35天烟测。完整烟测添加 `--days 365 --timeout 1800`。真实图形验证另运行项目或截图测试。

预备队调防现使用固定驻地，计入在途增援并遵守命令／驻防锁；正常战役、首次赴任仍会行军。行为及耗时对照见 [预备队固定驻地](RESERVE_STATIONS.md)。

野战军实际军费和军粮现按存续编制计费，战损不释放维护预算，补员只耗人力；正常扩军检查钱粮，预算撤编释放完整编制费用。虚拟守军保留原规则，见 [满编维护口径](FIELD_ESTABLISHMENT_COSTS.md)。

详细模块、验证证据和遗留限制见 [军事接入](MILITARY_INTEGRATION.md)、[贸易与君主](POLITICS_TRADE_INTEGRATION.md)、[目录维护](WORKSPACE_HYGIENE.md)与[旧实现移除](LEGACY_REMOVAL.md)。旧实现和历史性能资料可在Git历史查询。
