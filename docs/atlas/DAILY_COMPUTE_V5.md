# 欧亚遮罩：复用战前评估的联盟集团

2026-10-10。既有日结算优化和欧亚遮罩已分别提交 `f456684`、`efc8055` 并推送至 `feature/civ-atlas-godot`。
从本轮开始，默认性能和优化验证场景为真实地球种子1、40国，北纬20°～55°、西经15°～东经145°。
原全球数据只作兼容回归，不能与本轮日均值拼接比较。

## 实际瓶颈与改造

以已推送版本生成484个真实治所、1192个含交通点的模拟节点，从第0天运行到第750天。
第750天独立插桩中，`alliance_bloc` 查询541次、约632毫秒；战前发兵门槛、敌方援军估计、宣战资格
反复重建相同联盟分量。月度外交中的备战评估约426毫秒。插桩耗时仅用来定位，正式对照不加这些包装。

- `DiplomacyAI` 的备战资格与兵力门槛复用同一评估批次的联盟缓存、现有围城需求缓存。
- `GameState.campaign_prewar_reinforcement_threat()` 可选接收本批次已确认的攻守联盟，旧三参数入口保留原行为。
- 军队位置、兵力、补给和有效作战资格继续现场计算；不缓存实时敌方兵力。
  守军需求键保留守军数、归属、行政及守军版本，联盟缓存按外交与归属变化刷新。
- 州战役的活跃记录与战前评估缓存放在不同字典层级；外交缓存失效不能清空战线调度与动员认领。
- 手动长跑审计今后默认读取欧亚输入、输出至 `.dbg/atlas-eurasia-thirty-year/`。
  已在运行的旧全球进程保持原世界、已加载版本和原目录，未重启、未混用其数据。

## 对照结果

冻结第720天的完整Simulation对象图（含内部AI缓存），两版本从同一对象图恢复，推进721～750天。
三组配对独立进程，轮换先后顺序，固定CPU亲和16；旧全球审计同时运行，进程、源码及时间记录在证据中。
每个版本各90个日样本，逐日检查完整Native状态指纹（含RNG）及领土、军队、道路、战团、宗藩、库存不变量。
180个指纹均与已推送版本从第0天运行所得的欧亚轨迹一致。

日均减少14.87%。P95没有可辨改善，不能称整体尾部延迟已解决；月末尖峰和均值确有下降。
这是headless同步计算，不能代表GUI帧率，也不能外推到几十年后所有战争状态。

## 回归和限制

新增专项先在旧代码明确失败，修复后32项检查通过：联盟只构建两次、军队数量与位置变化立即生效、
同州道路不重复计兵、饥饿军队排除、外交变化、守军变化、府失守、无效目标和死国回退。
综合测试505项通过；双方灭国事务、宣战方胜利、被宣战方反攻、补给门槛、外交批次缓存、
同步／分帧等价、项目编译和欧亚35天军事烟测通过。

第749～750天通过真实`advance_one_day()`分帧路径，完整状态与同步轨迹一致；
无渲染器的最大帧间隔分别19、121毫秒，月末仍有长任务。
这些诊断不能作为GPU帧率验收，后续仍需拆解AI规划及月度事务。

本轮没有完成新的欧亚30年审计。旧全球长跑仅是旧版本的独立行为证据。
