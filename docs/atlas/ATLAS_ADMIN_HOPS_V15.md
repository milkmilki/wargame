# Atlas 行政连通修复与分层遍历 v15

## 原因与正确规则

原查询要求每个物理道路节点都属于本国。Atlas 岔口及辖区分段点没有政治归属，因而把合法本国道路截断。真实第180天冻结状态中，已核实96条同国首都邻接治所路线受到影响。国家0的首都0到治所181，路径 `[0,558,181]`，其中558是交通点；现在正确返回一跳。旧诊断保留在 v14 证据目录，未拿旧错误算法的耗时作为等价基线。

新查询遍历真实共享道路：治所进入成本为1，交通点进入成本为0。道路须存在、容量为正、控制辖区有效且属于本国；外国治所不能作为行政中继，结盟不放宽这一限制。未知控制辖区和由交通点伪充的控制引用被拒绝。查询检查当前控制与容量，每次返回独立结果，不持有容易失效的长期缓存。军队通行权限仍使用原接口。

实际道路可能有环路，预选战略路线被关闭或经过外国辖区时，另一条本国路线仍可能可用。因此不能只检查那一条战略路线，也不能按“出事节点的跳数及之后”推断全部影响。分层队列先处理本层零成本交通点，再处理下一层治所，得到最少治所跳数。旧地图保留原物理节点BFS。

修复会改变原先误判断联地区的忠诚距离惩罚、虚拟守军费用及后续AI行为。不能声称相对旧错误版本逐日轨迹不变。后续性能验证应采用修正后的规则。
