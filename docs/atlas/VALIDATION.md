## 已记录的绘制差异与限制

算法输入对齐不等于逐像素复刻。当前原型仍有以下差别，需要用户看图后决定是否达到目标：

1. GPU Shader 使用浮点连续场，Canvas 使用字节查表／合成，水彩边缘、森林让色、透明度和抗锯齿有小差异；未执行全图 RGB 逐像素“相同”断言。
2. 海冰边链已完整对照，但冰面背光和排线通过原生 Shader 表达；没有逐层复制原版 Canvas 的阴影填色裁剪、InkPatch 与路径图案对象。
3. 国家／城市／地理实体文字使用同源中等字重、原版路径、字号、顺序、留白和九点地面采样；Godot 字形基线、栅格描边及最终避让候选仍与浏览器有差别。附加文字参考冻结国号和城市等级，不启用人口或历史。
4. 放大政治填色采用与点击同源的边段查询；海岸断头外的小范围回退采样与原版 nearestCellPixel 的规则仍有差别，需继续关注极窄海岸色带。没有把它称为新的逻辑划省。
5. 长海岸和波纹以原版 48 段尺度分块，再由 Godot 原生墨线网格绘制；极端锐角的细微接头覆盖可能不同。原版／Godot 放大对照用于人工检查。
6. 默认仍为随机星球、2D 等距圆柱；另有固定真实地球预设。预览不提供任意 DEM 文件导入、历史推演、3D 地球仪、其他投影、航线或在线功能。后续军事接入与正式入口见 `MILITARY_INTEGRATION.md`。
