# 海陆边界约束网格

目标：真实地球先确定海洋、陆地、湖泊分割，再采样并生成遵守分割的球面网格。现有 `mesh` 的点、三角形、CSR 邻接、长度、面积接口继续用于气候、行政区、城市、道路和航运。随机星球流程保持原有生成方式。

## 数据与几何约定

- 当前权威输入仍是通过 SHA256 校验的 `earth_water_06m.u8.gz`，0=陆地、1=海洋、2=湖泊。这个版本保护输入中已经存在的水道，不声称恢复源数据中缺失的海峡。
- 在撒点之前提取周期栅格的类别边界；相同类别之间没有海岸约束。两极是单一类别，日期变更线两侧相接。仅合并没有分支的共线栅格边，不改变栅格连通性。
- 原有球面 Poisson 采样提供内陆和远洋点，边界顶点补足海岸和窄水道。原生约束三角化在立体投影中强制保留所有边界，再封闭南极帽。
- 投影直线与渲染大圆边存在小量近似。若原始采样点过于贴岸，造成球面翻面，则批量拒绝这些内部点并重新三角化，最多三次；海岸约束点和边始终保留。仍不能构造有效球面时明确失败。
- 三角面按边界两侧类别播种并泛洪赋类，不按三角形中心的单个像素猜类别。共享岸点按同类连续扇区拆分，避免地块跨岸或对角接触制造陆桥/水道。
- 拆分点在几何上重合；跨岸邻接仅用于陆海接触、港口和环境计算。陆路仍要求两端是陆地，海路仍要求海洋。每个点的三角扇及其分摊面积只属于一种类别。
- 几何最近点查找使用包含全部扇区的邻接；通行使用实际扇区邻接。重复位置的环境长度使用数值下限，避免排水除零。
- 地球显示从所属纯类三角形读取海陆类别，噪声与高程平滑不能重新决定海岸。
- 保留原始 Poisson 采样标记和数量。沿陆地最短距离划分原始采样的候选区，每区只保留一个最适宜候选位置；允许候选移到岸边以复用原有港口判定。新增海岸点不会增加候选名额，无原始采样点的小岛仍有地形和行政归属，但不凭空新增城市。径流按实际面积加权，河流供水阈值和行政密度使用原始采样数量。

## 原生接口

独立 `NativeAtlasMesh` API 1，不改动模拟原生 API：

- `partition_water(width: int, height: int, water: PackedByteArray) -> Dictionary`：返回边界投影坐标、约束边、两侧类别和极点类别；失败返回 `error`。
- `build_mesh(partition: Dictionary, samples: PackedFloat32Array) -> Dictionary`：返回球面点、纯类面、类别及邻接；失败返回 `error`，不退回无约束网格。

边界数据由调用方持有，每次调用的数值暂存独立，运行时不访问网络。使用固定版本 CDT，随代码保留原始许可证，构建指纹包含依赖文件。

## 实现与验收

1. 先添加能失败的合成地图测试：窄海峡、细陆桥、小岛、湖泊、周期接缝、对角接触和两极。
2. 实现分割与原生约束网格，检查所有面纯类、约束存在、面积守恒、邻接对称、结果可复现、非法输入明确报错。
3. 接入真实地球流程及海陆显示，复用道路/航运/行政区入口，验证合成连通性和真实地球生成。
4. 欧亚基线固定 `seed=1`、40 国、`settlement_mask.enabled=true`、南20/北55/西-15/东145；记录生成耗时与地块数。全球仅作兼容检查。

## 本轮验证

- 合成地图覆盖窄水道、细陆桥、小岛、湖泊、对角接触、日期变更线、极区、纯类三角形、面积守恒、邻接对称、最近点采样及海陆显示不被高程改写。
- 真实地球种子 1、2、3、7、19、97：英法与台湾海峡无虚假陆桥，直布罗陀与英吉利海峡保持局部海路连通；种子 2、3 的贴岸翻面复现由采样质量拒绝修复。
- 固定欧亚种子 1、40 国：146,127 个逻辑地块（含沿岸补点），217 州、400 府、1,664 条道路段、205 条航线；原有模板往返、35 日状态审计与365日同步／分帧一致性通过。原生调试和发布 DLL 均已重建、校验。
- 本机一次新生成观测：基础生成约 62.3 秒、军事准备约 4.2 秒；改动前相同种子／遮罩约 34.4 秒、1.5 秒。这是首次生成成本，不是运行帧率对照。
- 博尔忽／泰兀的历史道路回归改用 `tests/fixtures/atlas_borokhul_roads.bin`，来源及哈希见同名 JSON。保留原始地形、道路和通行事实，省略仅供显示的栅格噪声列，加载时从原环境字段恢复这些列以验证模板结构。新地图单独验证，不依靠旧地图缓存代替验收。
