## 仍需单独评估的范围

- `candidates`包括超当前军队配额、同阶段长期驻营、长期备战等线索。配额可随失地降低，叛乱可带入既有部队；防守驻城可以长期静止。不能仅凭时间或配额判断异常，所有原始对象编号和日期均保留在各种子报告中。
- 进攻驻营、后方重整和长期备战的候选仍需结合权限、补给、战役门槛及道路核查；本轮不宣称所有军事停滞均已消除。既有州治110通路限制不归类为家谱回归。
- `wars_ended`／`war_ended`审计字段实际统计消失的战争编号；战争合并也会使编号退休，不能据此统计真实议和次数。
- 实机夺嫡采用受控人物／部队输入和逐日内部推进；完整模拟行为由headless长跑及同步／分帧测试验证。原始大快照留在本地`.dbg`，仓库保存摘要、源码哈希、日志与截图，避免复制大量临时数据。
- 家谱仅查看自动演化，只有既有国家君主类型与特质控件可编辑；没有新增人物编辑、外交抽签或地图夺嫡命令。未知年龄、生卒和任期不补造。

## 复现

从项目目录运行（`godot`替换为实际4.7.1路径）：

```text
python run_tests.py --godot <godot> --group core --timeout 300
python run_tests.py --godot <godot> --tests atlas_runtime_equivalence atlas_territory_transactions vassal_faction_conflict --timeout 600
godot --path . --script tests/atlas_family_visual.gd
godot --path . --script tests/atlas_family_canvas_gpu.gd
godot --headless --path . --script tests/atlas_long_audit.gd -- --audit-seed=1 --audit-years=30 --audit-directory=res://.dbg/family-repro-1
```

实机脚本禁止`--headless`。长跑使用独立空目录；其他种子按相同方式指定`--audit-seed=7`／`2024`和`--audit-years=10`。
