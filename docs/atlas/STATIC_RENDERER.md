# Atlas 静态世界图层

正式 `atlas_military.tscn` 与独立预览的高性能分支采用固定世界内容。
城市名称继续默认隐藏，在工具中开启后仅城市文字恢复按视野排布。

## 固定内容

- 自然符号使用覆盖2048×1024世界的4倍细节图。山峰、森林、树冠、沙丘、草地在进入世界时一次规划、绘制和GPU复制，之后不补瓦片、不切换符号细节档、不合成屏幕遮罩。
- 自然图与政治让色遮罩共用同一纹理，Shader按世界坐标采样。显示裁去准备阶段的边缘余量；跨经线副本共享纹理，不重新绘制。
- 城市标记使用固定4倍规划的全球MultiMesh，归属或城市数据变化时更新。拖动、缩放不筛选可见城市，不排序、不避让、不上传新实例缓冲。点击继续使用固定世界坐标命中框。
- 地理名称与国名分别保存固定世界坐标绘制命令，使用原字体与描边。地理名称只在地理布局变化时重新排布；国名只在其布局、国家数据或政治归属变化时重新排布。切换模式仅切换国名显隐，不能使国家名影响自然名称布局。
- 道路、国界、前线、海岸仍沿用持久矢量；军事标记、政治颜色及模拟仍动态更新。本轮没有修改生成、行政与军事规则。

拖动仅改变静态图层的变换；放大时符号与文字随地图等比例放大，不再自动增加森林细节或改变静态文字避让。8192×4096符号图在8倍视图中放大2倍，清晰度受其固定分辨率限制。

## 生命周期与缓存

首次进入世界等待全图自然纹理、固定文字和交通矢量准备好，之后新视野无需准备这些自然内容。自然纹理约128 MiB，GPU复制完成后释放森林、MSAA和规划网格的临时视口。支持没有RenderingDevice的兼容路径；无像素的headless测试保留冻结视口句柄。

固定资源纳入缓存计账，总预算为448 MiB；开发测量约398 MiB。政治后台任务及固定文字任务以独立版本取消过期结果；重载时释放旧自然图、经线副本及缓存记录。历史视图继续由对应快照的布局与归属驱动。

## 验证

`atlas_static_layers` 验证跨1／2／4／8倍和远距离平移不生成自然图或文字布局、不改变城市实例缓冲，跨经线点击有效；模式切换不排布文字，国名变化保留地理名称，城市名称开关可恢复和清除动态文字，退出释放缓存。

17项相关headless回归通过。真实GPU运行种子1、40国、1280×720、RX7600、Godot4.7.1、D3D12 Forward+。500次拖动及缩放调用期间模拟运行、工具栏及国家信息框开启：自然图准备次数1，固定文字无镜头触发重排，城市实例缓冲保持不变。

本次单进程PID24600帧P95 6.955 ms、P99 8.143 ms，档位检查P95 11.405 ms；细节跨区就绪约3～11 ms。模拟在这组快速输入中推进至第1天，测试暂停后等待当天完整结算再操作战争和退出；此结果不能替代后期大规模战争的性能评估。测量关闭VSync，正式设置不变。开发缓存只跳过生成，渲染和模拟实际执行。

真实GPU另覆盖政治易主、宣战前线、历史恢复、模式切换，以及窗口调整、世界重载、模板往返、资源释放。原始数据、截图和验证日志保存在 `static_renderer_evidence/`。本轮不自动提交或推送。
