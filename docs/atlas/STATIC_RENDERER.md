# Atlas 静态世界图层

正式 `atlas_military.tscn` 与独立预览的高性能分支采用固定世界内容。
城市名称继续默认隐藏，在工具中开启后仅城市文字恢复按视野排布。

## 固定内容

- 自然符号使用覆盖2048×1024世界的4倍细节图。山峰、森林、树冠、沙丘、草地在进入世界时一次规划、绘制和GPU复制，之后不补瓦片、不切换符号细节档、不合成屏幕遮罩。
- 自然图与政治让色遮罩共用同一纹理，Shader按世界坐标采样。显示裁去准备阶段的边缘余量；跨经线副本共享纹理，不重新绘制。
- 城市标记使用固定4倍规划的全球MultiMesh，归属或城市数据变化时更新。拖动、缩放不筛选可见城市，不排序、不避让、不上传新实例缓冲。点击继续使用固定世界坐标命中框。
- 地理名称与国名分别保存固定世界坐标绘制命令，使用原字体与描边。地理名称只在地理布局变化时重新排布；国名只在其布局、国家数据或政治归属变化时重新排布。切换模式仅切换国名显隐，不能使国家名影响自然名称布局。
- 道路、国界、前线、海岸仍沿用持久矢量；军事标记、政治颜色及模拟仍动态更新。本轮没有修改生成、行政与军事规则。

拖动仅改变静态图层的变换；放大时符号与文字随地图等比例放大，不再自动增加森林细节或改变静态文字避让。8192×4096符号图在8倍视图中放大2倍，清晰度受其固定分辨率限制。

## 生命周期与缓存

首次进入世界等待全图自然纹理、固定文字和交通矢量准备好，之后新视野无需准备这些自然内容。自然纹理约128 MiB，GPU复制完成后释放森林、MSAA和规划网格的临时视口。支持没有RenderingDevice的兼容路径；无像素的headless测试保留冻结视口句柄。

固定资源纳入缓存计账，总预算为448 MiB；开发测量约398 MiB。政治后台任务及固定文字任务以独立版本取消过期结果；重载时释放旧自然图、经线副本及缓存记录。历史视图继续由对应快照的布局与归属驱动。

## 验证

`atlas_static_layers` 验证跨1／2／4／8倍和远距离平移不生成自然图或文字布局、不改变城市实例缓冲，跨经线点击有效；模式切换不排布文字，国名变化保留地理名称，城市名称开关可恢复和清除动态文字，退出释放缓存。

17项相关headless回归通过。真实GPU运行种子1、40国、1280×720、RX7600、Godot4.7.1、D3D12 Forward+。500次拖动及缩放调用期间模拟运行、工具栏及国家信息框开启：自然图准备次数1，固定文字无镜头触发重排，城市实例缓冲保持不变。

本次单进程PID24600帧P95 6.955 ms、P99 8.143 ms，档位检查P95 11.405 ms；细节跨区就绪约3～11 ms。模拟在这组快速输入中推进至第1天，测试暂停后等待当天完整结算再操作战争和退出；此结果不能替代后期大规模战争的性能评估。测量关闭VSync，正式设置不变。开发缓存只跳过生成，渲染和模拟实际执行。

真实GPU另覆盖政治易主、宣战前线、历史恢复、模式切换，以及窗口调整、世界重载、模板往返、资源释放。原始数据、截图和验证日志保存在 `static_renderer_evidence/`。本轮不自动提交或推送。

## 2026-10-13：动态地图更新

本轮保留静态地形和自然符号，优化运行中的政治与军事显示：

- 军队位置使用显示层路线长度缓存和二分插值，每支军队每次变更只求一次位置。MultiMesh批量绘制可见军队及必要经度副本；Shader保持固定屏幕半径。选中环与战斗条独立保留绘制命令，选中、缩放和伤亡文字变化不会重绘全部军队。
- 政治填色拆为128×128 RF块，整图128块。缓存不可变的完整CPU版本、府到块的反索引、边界及国家名称；变更府和新增／删除曲线决定脏块，实际字节相同的块无需上传。保守覆盖曲线顺序变化，保留等距边界的原判定顺序。
- NativeAtlasDisplay API 1负责像素归属、边界距离、名称距离场、射线和文字拟合；原GDScript作为数值参考。只重新拟合受领土或国家数据变化影响的国家；全局距离场仍完整计算，避免截断造成阴影或名称差异。
- 双Texture2DArray采用主线程分步上传：后台只计算，非显示缓冲只更新不同的块。中途取消会保留已上传块的准确字节记录；下一批修复该缓冲后再切换。填色、点击数组与边界共同提交，旧地图在准备期间完整可见。
- 多次政治请求合并为最新快照，最多一个政治计算任务在运行；旧任务完成后只计算最新需求，不排队重算每个中间版本。准备工作和上传以不同调度域取消，重载不会误提交旧世界。
- 城镇的排序、避让和实例数据在后台准备，主线程只上传计划；文字用发布版本号替代每次扫描两百万像素的内容指纹。政治材质复用并重新绑定纹理，减少资源创建。主线程4毫秒是软预算，单次Godot资源调用和最终共同提交仍不能抢占，验收报告必须列出实测峰值。

两份128层RF纹理约16 MiB，纳入现有448 MiB缓存预算；CPU标签与不可变块缓存另占约16 MiB，前一版本的块由写时分离共享。缓存属于视图，重载与历史切换重新捕获显示输入，不写入军队、边或模拟快照，不消耗随机流。

实际小府变更的专项测试只上传1块（64 KiB），两府合并变更上传2块；前线分类、改名与无变化不上传归属块。初始化仍要准备全地图和静态自然纹理，不能用增量更新速度代替首次进入世界耗时。

### 第600天的同输入性能对照

使用欧亚遮罩（20°～55°、-15°～145°）、地球种子1、初始40国的同一份第600天存档，523支军队、5场战斗。D3D12 Forward+、RX7600、1280×720、关闭VSync，进入地图并预热30帧后分别采样120帧暂停／拖动／连续缩放／选军，再以32倍速自然分帧推进600～612天。初始化与截图编码不在性能窗口内。

基线为f3ab57a的8个原渲染脚本，通过忽略目录中的临时影子加载；模拟、引擎、输入和DLL均相同，基线没有调用新增显示内核。旧／新窗口顺序运行，采样期间没有其他测试并行。这里记录一对进程，不据此承诺所有机器或后续天数的帧率。

| 指标 | f3ab57a原渲染 | 本轮实现 |
| --- | ---: | ---: |
| 暂停帧间隔中位数 | 3.618 ms | 1.740 ms |
| 连续缩放帧间隔中位数／P95 | 65.512 / 82.739 ms | 2.840 / 4.457 ms |
| 切换选军帧间隔中位数 | 65.460 ms | 1.686 ms |
| 600～612天运行帧间隔P95 | 93.333 ms | 15.646 ms |
| 单次主线程政治发布峰值 | 18.898 ms | 8.380 ms |
| 暂停绘制提交调用数 | 5334 | 2069 |

计算时间单列：两次真实领土输入的归属指纹分别为1402996758和2484586175，旧版后台计算1760.558／1730.542 ms，新版236.246／260.751 ms，约减少85.8%。重复请求但没有领土变化是另一种负载：旧版仍全量重算，新版预热后约1.3～1.5 ms，不把这一结果当作真实占领的计算耗时。名称排布和GPU发布还需另行完成，后台计算时间不等于可见就绪延迟。

当前版共同提交最大4.628 ms，普通上传P95 0.118 ms，但一次不可抢占的Godot资源调用达到8.380 ms，因此4 ms软预算仍不是硬上限。此对照余下模拟尖峰在联盟规划，约17 ms；地图加速不代表模拟规则或所有月末结算也获得同样收益。

两份输入文件SHA完全相同，最终第612天的完整原始状态均为103,488,192字节，SHA为`c99d8ab7f933880dcd53eb4c79e15324581b301e2a535b2edbd2620a3c4da0ae`，逐字节相等，没有删掉缓存字段或归一化状态。原始数据保留在开发目录`.dbg/map-render-before.jsonl`、`.dbg/map-render-after.jsonl`和`.dbg/map-render-final-summary.json`；临时影子源和探针在退出时清理。

最终验证：162项回归的最新结果全部通过。首轮两个旧夹具失败（快照版本28断言、未完成共同记录首次激活即开始战斗），修正夹具后复跑通过，并保留当天不补兵、次日补兵保障。Debug和Release显示内核各3514项数值检查通过，原生发行契约及9项构建元数据测试通过。三个实际GPU入口通过，包括21项整图／重复采样／军队屏幕尺寸检查、真实占领中途取消、历史回放、模式切换、窗口变化、重载与地图模板往返；重载后的缓存计账388,084,800字节，低于448 MiB预算。本轮没有修改战争、伤亡、士气、围城和军队分配规则。
