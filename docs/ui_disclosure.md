# 信息栏折叠与视图下拉

## 行为

- 国家详情默认展开身份、经营区域和战争；城市展开概况；道路展开道路信息。
- 各分栏独立折叠，窗口也可整体收起；标题栏支持拖动，内容超出可用高度时内部滚动，长文本自动换行。
- 本次运行内按稳定分栏 ID 保存偏好，切换对象或关闭重开不重置。新战争默认展开；重新生成世界清除战争 ID 的旧偏好，避免 ID 重用串栏。界面偏好不写入地图或运行期快照。
- 国家列表保留排序、滚动和宗藩树。其原绘制逻辑放入独立 GUI 画布，保证与详情重叠时，显示层级与鼠标命中一致。
- 显示控制默认收起，不改变兵牌大小或城市、国家、道路的显示开关。
- 历史时间轴收起后保留日期，待处理拖动先提交一次；不会退出历史或改变暂停状态。
- 六种地图视图使用一个 OptionButton。历史浏览显示并禁用政治视图；返回实时恢复原视图，新世界初始化同步实际地图与选择框。

## 展示边界

MapRenderer 仍提供城市、国家和战争的详情数据。SelectionDetailPanel 只接收展示载荷，不读取 GameState，也不参与模拟。

载荷分组保留 title / lines，并增加稳定 id、default_expanded 和明确的 line_actions；底部行动独立传入。君主、族谱和城市跳国家使用原生按钮，不通过文字解析或固定行坐标触发。

DisclosureSection 只负责标题箭头和 body 可见性。详情面板持有本次运行内的偏好，并按 ID 复用分组和文本节点。绘制、布局、滚动和输入统一使用实际控件区域，删除原来的自绘详情、固定高度公式及行动命中矩形。

焦点位于原生控件时，空格用于控件操作，不触发全局暂停；重新选择地图对象时释放旧焦点。下拉菜单展开期间阻挡地图操作。

## 验证与性能

专项：ui_disclosure（32 项），ui_disclosure_scene（真实窗口、五档分辨率及截图，78 项）。覆盖状态记忆、动态战争、历史只读行动、滚动、鼠标与键盘输入、地图穿透、族谱、显示设置、历史模式恢复及新世界同步。2560×1440 另用 SubViewport 做精确尺寸渲染，避免 Windows 将大窗口限制到物理显示器尺寸。

已有的国家详情单次构建、君主菜单、城市视觉、前端场景、道路 UI 与州域视图测试均改为验证原生控件，不再依赖六个按钮或固定详情坐标。两项新测试纳入 run_tests.sh；真实 GUI 场景不使用 headless，以验证原生鼠标和键盘分发。

完整 run_tests.sh 已通过，主套件 1172/0，最终完整运行没有脚本错误。原有退出时 ObjectDB / 资源释放警告仍存在，本轮未扩大范围修复。最后的列表选中关闭与布局宽度调整另行重跑界面专项。
