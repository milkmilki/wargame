# 欧亚直接绘制逻辑省份

2026-10-08：按最新要求，停止新增面片省份方案。欧亚水文地图的政治、忠诚、贸易、行政视图直接使用现有 `GameState.province_ids`。地图源仍为 `eurasia_hydrology_map_source.json`，不重新生成省份，不升级模板版本（仍为 8）。中国默认地图保持原显示流程。

`ProvinceIdView` 仅把省份编号最近邻放大为填色纹理。可见边线由 `MapRenderer.build_province_boundary_topology` 从这些编号提取，沿用旧忠诚视图的共享边链简化和曲线细分。填色、国家边界分类和点击归属读取同一编号；海岸仍由现有地形遮罩裁切。颜色、忠诚、占领和分组变化只改变颜色，不重新运行视觉维诺图，不进行河岸改色修补。历史及模板恢复已有省份编号，编辑成功后刷新显示缓存。

道路显示直接读取已有 `Edge.map_path`，政治与贸易沿用同一折线。此项不改变生成阶段的道路路径；若源路径有格网折线，仍需在寻路阶段修复。河流继续绘制已有矢量路径。

后续已单独接入正式欧亚陆路可见性简化，详见 [正式欧亚陆路修复](eurasia_road_path_fix.md)。显示仍直接读取 `Edge.map_path`。

本次显示修复不承诺修正原始省份跨河、2% 密度下限或上游码头覆盖。这些仍是独立生成问题，不能通过显示层重新划区解决。边线平滑只影响描边，不修改逻辑格子归属或点击查询。

2026-10-08 边缘样式修正：3D 政治、贸易、行政视图曾额外启用按整数像素采样的区域边缘渐变，忠诚视图没有该层。虽然编号与黑色省界共用真源，这层配色增强仍会突出格网阶梯。欧亚直接编号模式现在统一沿用忠诚视图的边缘处理，停用这层额外渐变；同步刷新和异步纹理提交共用同一开关规则。旧中国地图保持原行为。这不移动或平滑省界几何，也不消除原始 256×256 编号网格的折角。

同日后续纠正：上述渐变调整没有修复忠诚视图平滑回退。真正原因是直接编号分支绕过了旧边链曲线处理，且统一填色开关使着色器用栅格距离场替代了原曲线描边纹理。现已移除该边界提取捷径，并将填色来源和曲线描边开关分开：欧亚各视图保持编号填色，同时使用旧忠诚视图的曲线边线。旧中国渲染分支不变。曲线是从唯一编号图派生的显示缓存，不是第二套辖区；格网填色与点击仍保持原有精度。
