# 国家备战意愿诊断

国家详情提供默认收起的“Debug · 备战意愿”。展开后按当前状态重新评估全部存活的普通目标国家，显示地理候选、实际双边评分或首个硬否决原因。历史详情不提供实时诊断。

诊断由 DiplomacyAI.war_desire_breakdown() 调用原有 war_desire()。只在诊断缓存启用时保存评分中间量；正常外交决策不生成诊断数据，也不修改评分、门槛或评估顺序。被硬否决的对象不继续计算假设分数。

有限分数展示目标州价值分项、九项正向收益、君主战争收益倍率、侵略性、外交态度及多线扣分。当前最高双边意愿不等于当轮一定行动：藩国自主扩张限制、已有备战、取消冷却和外交批次占用仍由原流程处理。

收起时不构建诊断。展开选择、对象或详情状态变化时重建，未变化的绘制复用已有详情缓存；不增加模拟每日任务、不写入存档、不消耗随机数。专项 tests/war_desire_debug.gd 已纳入 run_tests.sh，覆盖评分重构、州价值重构、征服者、暖缓存、外交失效、只读、折叠和历史隔离。
