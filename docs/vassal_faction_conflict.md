# 经营区域可达性与阵营内战

经营区域和普通宣战共用主权发起者的战前可达入口：和平藩属提供边界与借道，但孤立藩属自己能出兵不等于宗主能够到达。候选包含合法水路远征，保留现有评分与排序。目标区域仍有本国或和平藩属实控城、或仍有合法入口时继续保留；否则重选，无候选回当前控制最多区域。兵力不足与临时战斗不改变地理可达性。

`GameState.plan_vassal_conflict(subject_id)` 是只读查询，返回 `reject`、`independence` 或 `war`，携带参与者、两方首领、忠诚快照和领土/外交/路网版本。`start_civil_war` 保留布尔接口，成功的实际结果在 `last_vassal_conflict_result`。当前制度是单层宗藩，拒绝多层图及重复内战，不暗中省略参与者。

Atlas 可达性按道路的 `control_city_id` 投影阵营通行权，交通点的显示归属不决定通行。最终敌城辖区可能包含多段道路，因此从目标沿本城辖区反向寻找友方可达边界；中立辖区、其他敌城辖区和零容量道路仍然阻断。投影不改写实时外交、不消耗随机流。`atlas_campaign_reachability` 覆盖正式寻路对照与真实内战启动，防止有合法陆路的藩国误走隔离独立。

先按现有合法陆路、渡口、水路与借道预检首领双方。双方均无入口时仅起事藩王独立，不检测其他藩王、不创建战争或起兵军；保持国家 ID、军队、血缘、国家等级及本国爵制，切分原共享粮池并停止贡赋，与原体系成员中立并停战180天。有入口才一次性检测全体其他直属藩王：忠诚不高于25支持起事者，其余支持中央；站队不要求主动反叛的军力、冷却或成熟条件。阵营预计算后检查双方阵营的可达入口，可以先攻敌方挡路藩王；仍隔离则丢弃站队方案并仅起事者独立。

所有跨阵营关系使用同一个 `war_id`，同阵营互相通行，立场在战争中固定。起事首领沿用原有起兵军及征服者倍增，其他藩王正常动员；共享粮池份额对同一个旧库存计算，分别切出各反叛藩王，中央保留余数。战争中暂停同体系重复削藩与反叛。低直辖占比不再触发自动解体。内战目标豁免经营区域和主动扩张性格，战术集结、兵力和攻城门槛仍有效。普通外部盟友不由内战或联盟闭包新增参战；既有外战保持独立，不能与内战合并战争 ID。

仅首领首都失陷决定整场胜负。攻城者属于哪个阵营，就由该阵营首领吞并败方首领国家；其余存活藩王保留国家、改隶胜方首领。普通成员的临时内部占领归还法理所属，外部占领不被改动。全部领土、宗藩、外交使用同一事务，失败不降级为普通首都投降；成功后复用兼并的资产、军队、家支与历史归档收尾，并执行普通捕获的驻军、军队落位和撤退处理。清除内战关系、州战役、军队绑定及军力池，结果只记录一次。首领遭第三国吞并时注销内战，保留真实外部归属；普通成员灭国仅从阵营移除。

国家信息显示中央方/反叛方及首领；史书保存独立、起兵、各藩王忠诚和胜负。政治历史冻结阵营数据，浏览不重新站队。Native **30** 保存 `vassal_conflicts`，校验阵营互斥、首领归属、关系/战争 ID、宗藩标志及结束后的军队/战役绑定；读取列前校验类型和长度，损坏快照返回正式错误。旧运行期快照不自动迁移；地图仍为新局模板。Debug日志保留实际seed/PID/日数，追加发动结果与冲突记录，不消耗随机流。

新增回归入口：`regional_access_recovery.gd`、`vassal_faction_conflict.gd`。覆盖隔离独立、忠诚25边界、真实州战役规划、外盟同步、首领及盟军的四条首都胜利路径、外敌吞并、成员退出、粮食人力守恒和Native畸形输入。主套件的普通战争主动胜利、被宣战方反攻灭国及原子失败回滚继续保留。`ai_longrun.gd` 每日追加阵营审计，默认四种子各1095日。

## 强藩长期存在与削藩胜算

中央直辖比例不再驱动宗藩解散，移除了低凝聚力阈值、连续计时、整树独立结盟及相应历史字段。每日仍调用 `VassalConflict.reconcile` 处理死亡首领和成员退出，不能随解散入口一起删除。普通战争、臣服、分封、继承撤并、明确独立与灭国清理沿用现有事务。

已移除按军力比 50% 强制反抗的规则。普通藩国削藩反抗沿用低忠诚、持续时间、双方冷却和军力条件，高忠诚藩国即使军力强大也可和平接受；征服者君主原有的必反与双倍起兵例外保留。执行重新判断当前条件，过期的 `resist=true` 不能强迫普通藩国反抗。

普通宗主预判反抗后，以真实阵营计划和合法通路统计可参战野战军；中央战力须至少为反叛方野战军、保守起兵估计与首领首都实际虚拟城防合计的 1.5 倍。外部盟友不作为内战参战者，隔离导致独立时不主动削藩，暴君保留冒险例外。原有财政/政治动机、和平、保护期和冷却仍适用。提交时重新检查，过期胜算不能导致盲目开战；明确政治命令不套用 AI 胜算门禁，但反抗与冲突合法性照常重新判断。

`vassal_centralization.gd` 覆盖原 50% 边界不再必反、高忠诚强藩和平接受、和平撤藩军队与国库守恒、低忠诚普通藩国和征服者反抗、阵营及帝国城防估算、外盟排除、只读随机流、过期动作、365 天低直辖存续，以及真实削藩启动后中央胜利和藩王反攻吞并中央的领土、军队、资源与唯一结果结算。旧解散专项已移除，原整州和家谱回归保留适用场景。Native 快照结构、地图模板及扩展 API 本轮不变。
