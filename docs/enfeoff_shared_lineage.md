# 共享族谱分封与军队政治归属修复

## 根因与修复

种子23456修复前1095天复跑退出码1，确认军队20、21、23、73、74均出现 invalid political patron。逐日诊断定位到国家5共享国家3族谱：第450天分封国家3太子人物18，使军队20、21、23依附失效；第480天分封人物20，影响军队73；第510天分封人物21，影响军队74。分封候选只按族谱亲缘筛选，未保护另一个国家的当代皇子；政治军队清理仅作用于分封者国家5，因此国家3军队保留已分封人物引用。

`PrincePolitics._busy()` 现在检查同族谱所有国家，排除其他存活国家的在位君主、太子、当代皇子和各国继承权冲突参与人物。宗藩关系解除后保护仍成立。本国闲置兄弟优先、非太子儿子其次的顺序保留；合法分封仍只将分封者所属人物军队收归中央。没有新增存档字段或修改快照版本，也没有事后清空其他国家的政治依附来掩盖错误。

`tests/enfeoff_shared_lineage.gd` 覆盖真实分封事务，并纳入 `run_tests.sh`。`tests/ai_longrun.gd` 增加逐日继承审计及首错记录，任意一天出现错误都会使长跑退出非0；原期末审计保持。

## 当前分封闭环复核（2026-10-16）

分封通过整州领土事务同时转移实控与法理，按产能守恒划转国库和人力，既有正规军仍归宗主。藩国随后使用正常资源门槛募兵，并参与战争连通体的共享攻防计划。同宗藩王保留亲王爵，后代沿用袭爵；政治归属和换代在藩国，俸禄供养在宗主，不重复收费。

藩国城市钱粮的就近治理倍率为1.5，最终产出仍叠加君主、战乱等既有规则。和平贡赋默认按城市金产出的25%结算，战时后方藩国最低60%，前线藩国保留正常税率自行参战。粮食库存仍只在宗藩根粮仓，藩王首都是零库存、零距离损耗的中继；本地道路与城市通行规则继续约束从中继到军队的路线。分封收益取决于治理距离和中央收入损失，不代表每次分封都增加中央净收入。

此次发现直接粮源查询保留了旧单源搜索，漏计藩王首都中继，与日结网络结果不同。`Pathfinding.supply_sources()` 改为复用日结使用的网络和位置解析，移除重复算法；日结原有的中继与实际扣粮规则保持。新增 `vassal_supply_relay` 双后端26项，覆盖真实分封、实际募兵、驻城与边上粮源、根粮仓扣粮、空仓、粮仓封锁与解围、实际中立城市和关闭本地道路。两处旧断路夹具同步改为城市节点规则，不能再用道路辖区冒充封锁。

`atlas_enfeoff` 增加真实月结的双方国库核对、供养域与中继验证，并按月观测自然分封。种子1、40国、欧亚遮罩、贸易与随机君主开启，自动365天1421项检查通过；10次分封动作产生12个藩国，其中11个已募兵，7个被观察到绑定共享战役、8个被观察到行军；末期新封的一个尚未募兵。127个藩国月度样本没有欠军费，俸禄均记在对应宗主。此项证明机制实际运转，未进行分封开关的长期统一速度A/B比较。

其中桂由王在第270日的两支军队供给为零：宗主唯一粮仓儋津正被围，虽余12017粮仍禁止向外供给；第300、330日根粮池已经耗尽。复查直接查询、重新构建网络和日结缓存均一致。中继不产生库存，也不能绕过根粮仓封锁，这些样本不属于分封断供错误。
