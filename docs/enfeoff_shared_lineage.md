# 共享族谱分封与军队政治归属修复

## 根因与修复

种子23456修复前1095天复跑退出码1，确认军队20、21、23、73、74均出现 invalid political patron。逐日诊断定位到国家5共享国家3族谱：第450天分封国家3太子人物18，使军队20、21、23依附失效；第480天分封人物20，影响军队73；第510天分封人物21，影响军队74。分封候选只按族谱亲缘筛选，未保护另一个国家的当代皇子；政治军队清理仅作用于分封者国家5，因此国家3军队保留已分封人物引用。

`PrincePolitics._busy()` 现在检查同族谱所有国家，排除其他存活国家的在位君主、太子、当代皇子和各国继承权冲突参与人物。宗藩关系解除后保护仍成立。本国闲置兄弟优先、非太子儿子其次的顺序保留；合法分封仍只将分封者所属人物军队收归中央。没有新增存档字段或修改快照版本，也没有事后清空其他国家的政治依附来掩盖错误。

`tests/enfeoff_shared_lineage.gd` 覆盖真实分封事务，并纳入 `run_tests.sh`。`tests/ai_longrun.gd` 增加逐日继承审计及首错记录，任意一天出现错误都会使长跑退出非0；原期末审计保持。
