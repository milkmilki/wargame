# 战斗开场四骰

每场有效交战开始时独立生成四个整数骰：双方发挥、双方展开，范围0至10（含端点）。发挥倍率为1+0.1×骰数，同时影响本侧攻击与防御；展开后的本侧宽度为floor(基础宽度×(10+展开骰)/10)，允许突破常规地形宽度，但不能投入超过实际人数的兵力，也不改变行军通行容量。均值均为1.5，不额外归一化。

Battle保存原始骰值和交战序号，使用世界种子、战斗ID、交战类型和序号的专属随机域，不消耗全局随机流。Combat只读取固定骰；旧共享伤害骰、逐回合±5%战术随机及空间战术键已删除。军队基础属性、AI军力估算和R/C/V人数门槛不读取战斗骰值。

道路野战固定至结束。围城内真实野战每场单独生成，援军共享本侧骰，不重掷；野战结束清除野战骰。攻城仅在实际攻击虚拟守军时生成，封锁不抽骰；解围战或暂时退回封锁不会清除攻城骰，恢复攻城时沿用。第三方接管、目标城市易主或行政结束使旧骰失效，不产生额外奖励。

战斗日志规则版本为4，记录固定四骰、实际倍率、基础宽度及双方有效宽度；回放恢复当时骰值，不读取当前国家或重新随机。原生快照版本为22，包含两种骰组与序号，旧运行期版本按严格校验拒绝；地图格式不变。

功能测试显式给定骰值，统计测试使用真实随机骰。完全对称双方允许分出胜负，不再要求20%兵力优势永不翻盘；交换固定骰值和阵容后的伤亡/胜败对称性、拆分不增益、同种子复现仍严格要求。
