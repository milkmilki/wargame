# 战斗详情与家族树关闭修复

地图上的战斗兵力条及上方文字现在可点击，打开现有信息侧栏。点击区域随缩放保持屏幕尺寸，并支持地图的经度重复副本。军队详情中的战斗编号也可进入战斗详情。

详情采用“指标／甲方／乙方”三列并排表格，双方的同一项数据逐行对齐；围城时列名使用围城方、守城方或挑战方。当前兵力、有效士气、下轮有效火力和平均防御位于最前面，随后列出补给、君主攻防和士气倍率、军费、地形和驻防修正、开场发挥与展开、前线与预备兵力。参战国家、军队和城市可继续点击查看。

规则 v7 下，士气只控制溃败，不再折算攻防、实际火力或 AI 战力。详情删除旧的“士气战斗效率”行，并提示当前规则；君主士气倍率仍修正有效士气与储备，具体行为见 [士气仅用于溃败](morale_rout_only_20261012.md)。

比较侧栏宽度为 560 像素，在小窗口中受视口边界约束，两侧数据等宽、长文本自动换行。关闭或进入普通国家／军队详情时恢复常规宽度。较宽的详情显示时也提升同级输入顺序，防止工具栏覆盖关闭按钮；原有控件复用机制支持两列数值直接更新。

显示按当前日结算完成后的状态刷新，沿用侧栏每半秒更新机制并复用控件。分帧结算过程中保持上一个完整文档；首次查看等待当日提交。数值来自 `Army` 属性和 `Combat` 的纯计算函数，查看不会解算战斗或生成开场骰。

## 数据边界

- 道路野战和城下野战采用共享士气，包含预备队的贡献。
- 城内守军不参加城下野战，单独列为城市防卫储备。纯围城详情读取持久城市守军，不向真实战斗数组挂载临时部队。
- 未生成开场骰时，相关数值显示“待开场”；封锁时不声称双方已经进行攻城交战。
- 对已经移出活跃列表的战斗，保留最后查看的、有日期的记录并明确提示结束；这不是完整历史战报。
- 政治历史快照没有战斗记录，详情明确提示未记录；换世界不会复用旧战斗详情。
- 均值仅用于展示，真实结算仍逐军应用修正。军队详情列出本军的倍率和修正后攻防。

## 家族树关闭

原因是家族树先于工具栏加入界面节点。`z_index` 使家族树显示在前，但鼠标 GUI 命中仍按兄弟节点顺序分发，后加入的工具栏接收了关闭按钮区域的点击。

家族树每次打开时移到同级节点末尾，让显示与鼠标命中顺序一致；关闭按钮增加“关闭家族树（Esc）”提示。

新数据测试将详情的火力、防御与实际战斗回合日志逐项比较，并校验纯围城守军与真实临时守军属性一致、查看不修改军队顺序和随机流。家族树关闭测试通过真实鼠标按下和释放复现并验证修复，没有直接调用按钮信号代替点击。
