# 帝国认可、宗室爵位与实封

主权国保存建国首都词根（游牧为完整音译名，其余为单字），显示时按两级等级派生正式国号：游牧为“某部 → 某汗”，其他六种建国环境为“某国 → 某”。合法、和平地整合一个贸易区域即可升格，之后不降级。地图大字、国家页面、列表、战斗信息和新事件统一使用正式国号，完整显示“部／汗／国”等当前称号后缀。地图按命名与家族版本检查称号变化，只在显示内容实际改变时重排国家文字；历史回看使用快照当时的国号。迁都与继位保持词根和建国环境。旧模板显式多字国名按原文显示；藩王与叛军继续使用既有王号、军号，不再叠加主权后缀。主权国国号与人物爵号独立保存，实封爵位规则见下文。

国家首次完整整合一个有效贸易区域后晋为帝国，等级只升不降。每个区域必须由同一和平宗藩体系同时掌握全部政治有效陆城的法理和实控；普通盟友、叛乱藩属、未确认占领、码头和无效区域编号不计入。首次认可只发生于独立国家，在任人物记为太祖。国号字库 `name_kind` 不代表国家等级。地图定义是新局模板，导入后重新判断认可，不能把模板国号当成运行中的帝国资格。

帝国及其和平直属、间接藩国的合法整合州治，虚拟守军上限为 30000（普通为 15000）。普通盟友和未确认的外国占领地不享受加成；叛乱、断裂、灭亡或临时争位身份不向下传递帝国资格，原本已晋帝的国家仍保留本国制度。晋升和归附只改变上限，不凭空补兵；每月沿用 1500 人的基础补充限额、供给比例和本国人力扣除规则，被围城时暂停补充，实际守军承担原有粮食与军费。失去保护后不删除已经招募的守军，上限回落后停止超额补充。虚拟守军满编值和低效围城的最大值扣员读取动态上限，围城兵力需求随实际守军增长，野战军属性不变。

普通国家选择新备战目标时，对帝国及其和平藩国施加软威慑：本国军力不超过守方防御集团的 1.5 倍时，正的备战意愿乘 0.10；1.5～3 倍线性恢复，达到 3 倍后恢复原意愿。负分保持原值，帝国之间不施加此折扣。守方盟友计入既有防御军力，进攻方只计算本国。既有备战、手动宣战、参战、反攻和所有硬门禁沿用原流程。诊断展示基础分与威慑系数；晋帝同步失效守备与外交评估缓存，不消耗随机流。

`Nation` 保存等级、太祖 ID、认可日、本国爵制和换代次数。人物的 `title_payer_id` 继续表示政治朝廷；`title_funding_nation_id` 单独记录爵位俸禄供养国；`title_generation_nation_id` 记录成年、死亡与袭爵结算的朝廷。封国家支的政治和换代归属都是封国，直属宗主承担爵位俸禄；封国的国库、军粮、军费和行政支出仍由封国自行承担。`title_origin_nation_id` 是当前授爵机构，通常与供养国一致；嵌套收回时，本朝廷仍可作为合法授爵机构，上级宗主承担俸禄，不因此终止原爵。零级待继承子嗣不领俸。`title_history` 仅在真正授爵、改爵或终止时更新，保存当时国号、封号和起止日；仅增减封地不关闭这份爵号档案。人物 ID 与血缘保持稳定。

太祖的本国合格儿子授亲王，后世皇帝的儿子初授郡王。储君是附加身份，立储和废储只更新 `crown` 与继承人 ID，不撤爵。独立君主登基终止原虚爵且不递补，独立君主不领爵位俸禄；实封继承人则同时承接原藩王的等级、具体封号和封国。成年有爵家庭按均匀 `{0,2,3,4,5}` 生育一次，零子嗣不重掷。子代初授降一级，等待代不生育，国公子代无爵；正常直系及旁系继承仍可承接原爵。

人物显示具体封号：亲王从晋、秦、齐、楚、吴、越、宋取一字加“王”；郡王从既有地域字库独立取两个字加“王”；国公取一个字加“国公”。允许重名，不检查含义，不附加数字。取名依赖世界种子、人物 ID 和等级，不推进模拟随机源。爵位等级和财政规则照旧。

外来国家接受威服后保留原国号加“王”，即使同名封号已存在或曾被灭国，也不附加国家编号或重名计数；例如“长”归附后为“长王”。国家、人物和归属仍以稳定 ID 区分。已有编年史文本保留原记录，新兵变事件按实际爵位及改储后的封爵结果记载，见 [succession_resolution.md](succession_resolution.md)。

同源直系或旁支继承沿用原封号，降等旁支另取封号。取名加入授予国家域；新国合法授爵重新取名，同名不代表旧爵接续。人物当前身份只取现职封号或有效虚爵，无爵不回退历封；继承人另加徽标。Atlas 竖排谱图同时展示有记录的历次身份，点击人物查看起止日、爵号来源与结束原因；外姓家谱通过关联入口切换。读取保持只读。

实际朝廷的君主继位时，其成年虚爵家支同时死亡，等待代转成年。结算按换代归属和政治归属筛选，不能按俸禄供养筛选；宗主换君不会结算仍属封国的家支。每个原爵先找可用直系，再在同朝廷、同独立家谱、同爵支寻找最近旁系；出生顺序和人物 ID 打破并列。按亲王、郡王、国公顺序，每级全部直系优先，每个人最多承接一个旧爵。提前死亡同样结算，内部继承战争未结束时不提前换代。

皇帝、普通君主和实封藩王也按同一 `{0,2,3,4,5}` 分布生育一次；`children_initialized` 固定结果，旧 `title_children_generated` 的零子嗣结果同样继承，登基、授军和候选刷新不补生。储君可以为空。有效储君优先，其后直系按代数距离、长房顺序、人物 ID 递补，旁支按血缘距离、原爵等级、出生顺序、人物 ID 选择。启用爵位制度时庶民不入继，普通国家仍允许既有王族；候选限本国及下级和平同宗实封藩王，别国虚爵、储君与争位人物排除。

无现成人选时，正式登基入口才补录已故、未载名的旁支祖链及同代远支，保留旧血缘、国家等级和原太祖。只读 `PrincePolitics.select_successor` 返回人选、来源及需撤并的藩国，不创造人物或修改储君。藩王入继时原国并入目标国家，下级藩属改隶；先提交领土与资产迁移，期间延后帝国和爵位协调，再登基并换代一次。新君及存活亲生子嗣不作为旧代旁支处死；原国候选与旧军权解绑，已有孩子和生育结果复用。事务失败不改变君位、存亡或资产。同日宗主先于藩属处理，已撤并国家不再继位。没有可用分封人物时拒绝分封，不通过该入口补造兄弟。

分封是“爵位 + 封地”：同宗实封藩王为亲王，外姓归附藩王为郡王。原有合法爵位和具体封号保持开放，只新增实封身份；原本无爵的分封人物在这时建立相应爵位。现有子代复用原生育结果及降等袭爵逻辑，不为每个子代另建国家。和平收回封地经真实兼并事务提交后，保留有效爵位、原爵支与开放授爵记录，将政治归属及换代归属转回宗主，不重复授爵或生育。外姓保留独立家谱、姓氏及血缘。战争兼并依旧终止败国人物的现行爵位，即使胜者也是原授爵宗主；重复处理已归档败国在事务入口拒绝，不重复迁移人物或资源。

普通国家分封或接受归附时也可维护这些特定爵支；`royal_titles_initialized` 不代表帝国等级，不产生太祖，也不给普通君主的其他儿子自动授爵。独立国家首次晋帝才按既有规则授予本国合格皇子，不改变外国朝廷成员的政治资格。嵌套藩国改隶时保持政治朝廷、换代归属、血缘和合法封号，按新的直属宗主迁移供养，已失效的外部授爵来源随之调整并单独记档，本朝廷仍合法的原授爵保留。独立后的实际君主退出实封与爵位身份，恢复独立君位，其本国家支按新的合法授爵机构协调。临时争位国家沿用母国身份。

自然生育统一在 `PrincePolitics.initialize_children` 校验：在世的现任君主（含实封藩王），或所属本国、已成年的有效有爵人物才可生成后代。无爵旁支、等待代、已故人物及历史视图不生成后代，也不提前标记已生育；后来合法袭爵或登基后才按原分布完成一次生育。已有后代与已抽出的零子嗣结果均保留，不删除家谱、不重新抽取。

迁移仅在真实领土事务成功后更新。只有和平收回入口显式传递实际回归人物集合，保留合法授爵；普通兼并入口不使用该例外。共享家谱只处理实际迁移的人物，其他朝廷不被误迁移。所属封国灭亡但授爵宗主仍存时，也关闭该封国家支的有效爵位和开放档案；不视作和平收回，也不自动转入宗主。已失爵家支仍随接收朝廷换代，既不因旧爵生育，也不因无制度停止成年与死亡。

宫廷成本复用现有财政流，亲王、郡王、国公分别增加 30、20、10 基点（0.3%、0.2%、0.1%）。实封君主、其有爵子代与宗主本国贵族合计到供养国，按整个人口取整一次，封国不重复支付这笔爵位费用。叛乱或与供养国交战时暂停外部俸禄，但不删除合法爵位；财政缓存同时跟踪家谱、领土和外交版本。国库不足时沿用应付、实付和无新增债务规则。军费、军粮和封国基础宫廷开支仍按原财政流由封国承担。

政治历史冻结国家等级、太祖、政治归属、供养、换代、授爵来源、封地与爵号履历，不借用未来变更。Native 运行快照升至 **31**，明确拒绝版本30及更早快照；地图模板9和扩展 API7不变。校验授爵机构与合法朝廷关系、供养与换代引用、爵号档案开闭、外姓郡王上限、爵支和血缘、真实封地与实际君位一致、一人一国在位。`identity_history` 增加 `fief_nation_id`，按时间分别记录同一爵号的无封、实封和收回阶段；旧履历缺失不推造。

家族姓氏固定为初代君主的姓，子嗣、旁支和补录远支只随机名字。Atlas 采用纸色竖排谱牒，树上省略重复姓氏，详情和搜索保留全名。具体爵号旁显示“亲王·无封 → 亲王·实封 → 亲王·收回封地”，外姓用郡王；点击人物查看供养、所属朝廷、换代归属及各段日期。历任皇帝保留朱色双框和帝印。详见 [Atlas 家谱](atlas/FAMILY_SUCCESSION.md)。

回归入口新增 `royal_landed_titles.gd`，并调整 `royal_title_origin`、`royal_title_lifecycle`、`royal_foreign_recall`、`royal_title_audit` 与家谱测试。覆盖真实分封、归附、封国继位、和平收回、嵌套改隶、宗主换代隔离、单次俸禄、历史冻结、快照负例，以及进攻者胜利和被宣战者反攻兼并的战争清理。25代测试继续走真实换代和独立财政校验。

人物去世时冻结 `death_title`，关闭当前身份与爵号履历；死亡后不再领俸，卡片保留最后实际封号及帝号记录。和平分封与收回不结束爵号，战争兼并、改爵和独立登基仍会结束原爵，死亡不能恢复此前已终止的爵位。无记录时不猜测。

外姓爵支的生育与直系／旁系袭爵按人物所在独立家谱查找，不能因宗主供养而加入宗主皇室的继位候选。财政人口统计保留相关家谱入口；快照校验来源、供养、朝廷和代际分别一致，爵支根与血缘引用位于本谱，外姓有效爵位最高为郡王。

外姓回收专项回归覆盖真实归附与撤藩、嵌套藩属改隶、两个独立家族同时袭爵、提前死亡的直系／旁系承袭、姓氏保持、宗主继位候选隔离、历史回看和快照负例。离职时将首代君主原来仅保存在国家上的类型与特质写入人物档案，避免转为虚爵后丢失已知信息。
