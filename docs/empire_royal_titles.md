# 帝国认可与虚衔宗室爵位

国家首次完整整合至少两个有效贸易区域后晋为帝国，等级只升不降。每个区域必须由同一和平宗藩体系同时掌握全部政治有效陆城的法理和实控；普通盟友、叛乱藩属、未确认占领、码头和无效区域编号不计入。首次认可只发生于独立国家，在任人物记为太祖。国号字库 `name_kind` 不代表国家等级。地图定义是新局模板，导入后重新判断认可，不能把模板国号当成运行中的帝国资格。

`Nation` 保存等级、太祖 ID、认可日、本国爵制和换代次数。人物的 `title_payer_id` 表示所属与供养国家，无爵仍保留；`title_origin_nation_id` 保存当前授爵来源，有效虚爵的来源与供养必须一致。零级待继承子嗣保留本国爵支来源但不领俸。`title_history` 保存来源 ID、当时国号、封号、等级、开始/结束日及结束原因，仅真正授爵、改爵和终止时更新。历史来源允许灭国。血缘和人物 ID 保持稳定，`titles` 只供历史及皇帝双框判断，不回退为当前称号。

太祖的本国合格儿子均授一字王，后世皇帝的儿子初授郡王。继承人是附加身份，与兄弟使用相同爵位、俸禄、生育规则；`PrincePolitics.set_heir` 仅更新继承人 ID 和 `crown` 标识，立储、废储不撤爵或恢复爵位。登基终止本人原虚爵，不递补该爵；实际君主不领虚爵俸禄。每个成年有爵家庭按均匀 `{0,2,3,4,5}` 生育一次，包括零子嗣，不会重掷。孩子先降一级领俸，等待代不再生育；国公旁支无爵。

人物显示具体封号：一字王从晋、秦、齐、楚、吴、越、宋取一字加“王”；郡王从既有地域字库独立取两个字加“王”；国公取一个字加“国公”。允许重名，不检查含义，不附加数字。取名依赖世界种子、人物 ID 和等级，不推进模拟随机源。爵位等级和财政规则照旧。

外来国家接受威服后保留原国号加“王”，即使同名封号已存在或曾被灭国，也不附加国家编号或重名计数；例如“长”归附后为“长王”。国家、人物和归属仍以稳定 ID 区分。已有编年史文本保留原记录，新兵变事件按实际爵位及改储后的封爵结果记载，见 [succession_resolution.md](succession_resolution.md)。

同源直系或旁支继承沿用原封号，降等旁支另取封号。取名加入授予国家域；新国合法授爵重新取名，同名不代表旧爵接续。当前家族树、名单和 HTML 显示现职封号或有效虚爵，无爵不回退历封；继承人另加徽标，共享谱外国人物标明所属。悬停人物或名单可查看爵号来源与结束原因，HTML 点击人物可查看档案。读取和导出保持只读。

本国实际君主继位时，成年虚爵家支同时死亡，等待代转成年。每个原爵先找长子及其后的可用直系；没有直系时在同供养国家、同最初爵支内找最近旁支，出生顺序及人物 ID 打破并列。按一字王、郡王、国公顺序，每级先全部直系再处理旁支，每个人最多承接一个旧爵。镇压造成的提前死亡同样结算继承。继承战争未结束时不提前换代。虚爵人口与掌军/争位候选列表分开。

皇帝、普通君主和实封藩王也按同一 `{0,2,3,4,5}` 分布生育一次；`children_initialized` 固定结果，旧 `title_children_generated` 的零子嗣结果同样继承，登基、授军和候选刷新不补生。储君可以为空。有效储君优先，其后直系按代数距离、长房顺序、人物 ID 递补，旁支按血缘距离、原爵等级、出生顺序、人物 ID 选择。启用爵位制度时庶民不入继，普通国家仍允许既有王族；候选限本国及下级和平同宗实封藩王，别国虚爵、储君与争位人物排除。

无现成人选时，正式登基入口才补录已故、未载名的旁支祖链及同代远支，保留旧血缘、国家等级和原太祖。只读 `PrincePolitics.select_successor` 返回人选、来源及需撤并的藩国，不创造人物或修改储君。藩王入继时原国并入目标国家，下级藩属改隶；先提交领土与资产迁移，期间延后帝国和爵位协调，再登基并换代一次。新君及存活亲生子嗣不作为旧代旁支处死；原国候选与旧军权解绑，已有孩子和生育结果复用。事务失败不改变君位、存亡或资产。同日宗主先于藩属处理，已撤并国家不再继位。没有可用分封人物时拒绝分封，不通过该入口补造兄弟。

创建新国家（包括分封）时，实际迁入家支立即结束旧国爵位，不带入俸禄或按旧爵繁衍的权限。原国不补位，撤藩、同宗及异宗兼并不恢复旧爵或待恢复资格。国家级新国没有虚爵制度，但君主、继承人、血缘及孩子正常保留；首次晋帝才授本国太祖的国内合格儿子，不补授已实封到别国者，不重授共享谱外国人物。国家改名、换君主、接受威服和已有帝国成为藩属均保持同一国家 ID 和本国制度。临时争位国家不是实际建国，起事者仍领母国爵位。

迁移在真实领土事务成功后才更新所属、终止旧爵并刷新财政；失败不提前改动档案或资源。只处理实际迁移家支，共享谱其他国家不受影响。兼并保留独立谱及旧国家归档。生命换代与授爵分离，既有失爵家支随接收国君主推进成年和死亡，不因旧爵继续繁衍，也不因无制度停止换代。

宫廷成本复用当前月净收入及既有基础宫廷耗费，宗室为额外加项：一字王每人 30 基点、郡王 20 基点、国公 10 基点（0.3%、0.2%、0.1%）。包括继承人和等待代低爵，只计算本国有效爵位，按整个人口合计后取整一次。成本可以超过收入，实际支付以国库为上限，未支付仍保留应付记录，不新增债务。统一人数报告按族谱/领土版本缓存，真实月结、财政预测和 AI 预算共用同一财政流。

政治历史冻结国家等级、太祖、供养、来源、爵号档案、代际、生育/补录标记和费用；浏览不授爵、生育或晋帝。Native 快照版本为 **25**，验证来源/供养一致、档案开闭状态、爵支/太祖引用、祖链无环、实封虚爵互斥和一人一国实际君位。按新局生效，不猜测或自动迁移 Native24 运行家谱；地图仍为新局模板。树布局、视口绘制、40 人分页、当前君主定位和历史只读保持原规则。

家族姓氏固定为初代君主的姓，子嗣、虚爵旁支和补录远支只随机名字；旧运行家谱在谱系初始化时一次性修正姓氏，保留人物 ID、已有孩子和生育结果，历史快照不修改。家族树页面、侧栏、按钮及历史文字统一使用黑色加粗仿宋（字体可用时），双轴滚动会重画进入视口的卡片；切换历史模式时隐藏整个树滚动区，使历史记录占用完整内容区。

回归入口另含 `royal_title_origin.gd`、`royal_title_cross_payer.gd`、`royal_chronicle_names.gd`、`royal_title_ui.gd`、`family_tree_html.gd`。25 代测试走真实模拟继位，四种子各 1095 天长跑逐日审计政治及爵位，兼并覆盖主动方胜利和守方反攻灭国。
