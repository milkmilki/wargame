# 家族树 HTML 导出

家族树页右上角的「导出 HTML」可保存当前家族的完整谱系，默认保存到文档目录。文件独立包含数据、样式和交互代码，可直接用浏览器离线打开或转发，无需服务器或外部依赖。

拖动或滚轮平移，Ctrl＋滚轮及放大/缩小按钮调整比例。「定位当前君主」恢复到君主所在位置，「全谱总览」查看整体结构。搜索支持姓名、爵位和人物标记，同名人物附带不同编号；点击人物可查看历史封号及父子关系。大型家谱只绘制视野内的卡片，搜索结果每批加载50人。文字采用黑色加粗仿宋，设备未安装仿宋时使用衬线字体回退。

导出的是点击按钮时的快照，选择保存位置期间模拟推进不会混入新一代。历史视图导出其所处时间的冻结谱系；共享家族包含同宗藩王、已故人物、补录远支和撤并政权留存的人物。异姓家族仍为独立谱系，可进入对应家族另行导出。

`FamilyTreePanel.build_export_html()` 刷新现有画布布局并复用 `FamilyTree.display_title()`；`FamilyTreeHtml` 仅序列化只读数据，不初始化生育、修复人物或触发爵位协调。姓名和标题以转义后的 JSON/HTML 保存，浏览器以 `textContent` 填充人物文本。保存失败会显示错误，取消保存不生成文件。

历任皇帝使用双线框，当前君主额外使用红色顶边。判断基于已保存的当前及历史帝号，去世或改封后仍保留特殊框；普通君主、皇太子和仅有虚爵者不会因此获得皇帝框。游戏页与导出文件共用这一规则。

验证：`tests/family_tree_html.gd` 覆盖完整谱系、皇太子显示、特殊字符、文件保存及失败、历史只读、保存时快照冻结、分封及撤藩后的共享谱系和真实多次继位后的导出。设置 `FAMILY_HTML_LARGE=1` 可执行25次继位；`FAMILY_HTML_OUTPUT` 可指定浏览器验证用的输出文件，并生成同名 `-large.html` 完整谱系文件。`tests/family_tree_html_browser.cjs` 使用 Playwright 在真实浏览器检查离线加载、完整人物坐标、搜索、父辈跳转、缩放、平移和不同窗口宽度。
