# 普通战争增援职责收口

## 决策

普通战争的近邻主战增援与重点城市独立派兵入口停止调兵。兵力需求、承诺和军队绑定统一由州战线分配器管理，避免在战线之外重新追补战力。

皇子继承权战争保留原近邻与重点城市规则，包括1.25战力估值和特殊参与者。入口使用 _succession_battle_context 显式隔离。野战 C/R/V、45000进攻分兵目标、90000第二战场资格、战报锁定和真实行军沿用人数规则阶段的实现。

## 防守完整性

- 防守任务根据有效入侵、实际围城、合法来袭路线、敌占府与相关后方大营产生。只有外交目标时不会常驻调兵。
- 候选州按战争ID、州治归属国索引，在每个战争组件中合并联盟成员的候选；同战争同联盟同州只生成一个任务。
- 未登记州可创建额外防守任务，不占双方最多两个主动经营战场名额。该任务没有主动进攻、反攻接续或跨区域进攻资格。
- 已经参战且没有其他有效战线的正规军，以及有真实有效路线的在途援军，可以接入防守绑定；不改写当前战斗、路径或行动目标，不抢占其他战线。
- 接管有效野战立即冻结战报。已有参战军绑定其他战线时仍会锁定新防守任务；首次接管不补派新一轮。多个相关交战要全部结束才解锁。
- 封锁、敌占府或来袭仍在且有效V为零时保留现有一军最低需求。威胁消失并且相关交战结束后，由原任务结束流程释放。
- 有效在途军计入已经绑定的承诺量，与实际空闲到场分别显示。任务保持原行军路线，道路失效后不作为有效可达承诺继续填缺口。
- 攻击下令、进入道路及进入战斗唤醒被威胁国家的AI；兵力仍在正常规划批次中分配。批次复用联盟缓存，避免每条攻击命令重算联盟。

额外任务可能分散可用进攻军，也可能在多个受威胁州之间竞争预备军。这是统一分配后的行为变化；战场上限限制主动经营战场，不能保证全国兵力不会集中。
